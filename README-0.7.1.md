# 써클러(circlr)

macOS용 송폼 중심 DAW · **0.7.1 로컬 프로토타입**

Verse·bridge·chorus를 원형 서클로 만들고, 연결·반복·이동·변형하면서 곡의 구성을 설계한다. 오디오와 MIDI를 함께 사용하며, 음색 처리와 섹션 사이 전환을 편곡에 포함한다.

**최신 목표: 앨범 → 곡·악장 → 섹션 → 오디오·MIDI·이펙터를 모두 서클로 표현하고, 확대하면 같은 캔버스에서 직접 정밀 편집한다.** [앨범 전체 작업 공간 구현 계획](docs/14-album-circle-implementation.md)이 현재 기준이다. 앨범의 저장·시간 계획 core를 추가했으며 중첩 캔버스·내부 음악 그래프·직접 상세 편집·실제 오디오 검증은 진행 중이다. 아래 0.7.1 사용 안내는 아직 갱신하지 않은 배포본의 현재 동작을 설명한다.

초기 설계 문서와 후속 요청으로 만든 실행 가능한 macOS 앱을 함께 보관한다. 첫 프로토타입은 Swift·AppKit/SwiftUI·AVAudioEngine·CoreMIDI를 사용한다. 제품 전체의 장기 사양과 현재 구현 범위는 [구현 계약](docs/08-prototype-contract.md), 실제 확인한 결과는 [검증 기록](docs/09-prototype-verification.md)에 구분했다.

## 실행

이 작업에서 생성한 앱: [dist/써클러.app](dist/써클러.app)

macOS 14 이상을 대상으로 빌드한다. 현재 검증 환경은 Apple Silicon Mac, Xcode 26.6 / Swift 6.3.3이다. 앱은 로컬 ad-hoc 서명이며 공증·배포 release가 아니다. 기본 Sound Bank는 macOS에 설치된 음원을 사용하고 프로젝트는 빈 곡에서 시작한다.

```sh
./scripts/build-app.sh
```

전체 자동 검증과 오디오 증거 생성:

```sh
./scripts/verify.sh
```

SwiftPM 명령을 직접 사용할 때는 `swift test`도 가능하다. 이 작업처럼 cache 쓰기 경로가 제한된 환경에서는 `./scripts/swift-local.sh test`를 사용한다. 실제 오디오 검증에는 macOS Audio Unit/CoreMIDI 서비스 접근이 필요하다. 파일 시스템 sandbox 안에서만 실행하면 native audio 검증이 실패할 수 있다.

기본 화면은 다크 모드의 큰 송폼 캔버스다. 좌우·하단 고정 편집 영역은 없다. MIDI·오디오와 설정은 필요할 때 별도의 사각 편집 창에서 연다. 편집 창은 탭 없이 하나의 뷰에서 음악 설정·트랙·MIDI·오디오·이펙트를 함께 보여 준다. 이동·크기 변경이 가능하며 하나를 재사용한다. 캔버스에서 다른 서클을 선택하면 열린 창도 그 서클로 전환한다.

메인 창의 **빨간 닫기 버튼 또는 ⌘W**는 창을 Dock으로 최소화한다. Dock의 써클러 아이콘을 누르면 같은 곡과 편집 상태로 돌아온다. 앱을 완전히 종료하려면 **⌘Q / 써클러 종료**를 사용한다. 별도 음악 편집 창의 닫기·Esc는 해당 편집 창만 닫는다. [닫기 동작 검증](qa/0.7.1-close-review.md).

## 첫 곡 만들기

1. 빈 캔버스를 두 번 클릭하거나 상단 **+ 서클**을 누른다. 추가된 서클을 두 번 클릭해 편집 창 위에서 이름을 바로 바꾼다. 원 한 바퀴가 섹션 1회이고 마디·박 눈금이 테두리에 표시된다. 총 재생 횟수만큼 동심원이 생긴다: 1회는 원 1개, 3회는 원 3개다.
2. 서클 더블클릭 또는 선택 도구막대의 **편집**으로 창을 열고 트랙을 고른 뒤 빈 piano roll을 클릭해 note를 만든다. note를 끌어 이동하고 오른쪽 끝을 끌어 길이를 바꾼다. 선택 후 Delete로 지운다. 화면 건반이나 연결된 MIDI 장치로 연주할 수 있다.
3. 편집 창 위에서 마디 수·재생 횟수·템포·스케일·박자를 바로 지정한다. 재생 횟수는 캔버스 선택 도구막대에서도 바꿀 수 있다. Esc 또는 **닫기**는 창을 닫으며 캔버스 위치와 배율은 유지한다. 상단 BPM은 글로벌 설정 창을 연다.
4. **다시 사용**으로 같은 원본을 사용하는 서클을 추가한다. 기본 편집은 이번 사용에만 반영된다. **공유 원본 편집**은 공유 원본에 반영되며 기존 사용별 변형은 유지된다. **원본 분리**하면 별도 섹션이 된다.
5. 서클 오른쪽 포트를 다음 서클로 끌거나 **연결** 메뉴를 사용한다. 처음 서클에 **곡 시작**, 마지막 서클에 **곡 끝**을 지정한다. 분기는 재생할 연결을 선택해야 한다.
6. **재생**으로 전체 곡을 듣고, 편집 창의 **이 서클 듣기**로 선택한 구간만 듣는다. 실제 오디오 준비가 끝난 뒤 재생한다. 재생 중 편집한 음악은 다음 재생에 적용된다.
7. 상단 곡 이름 메뉴의 **저장**은 `.circlr` 곡 package와 원본 미디어를 함께 보관한다. 같은 메뉴의 **내보내기**는 stereo WAV 또는 트랙별 stem 폴더를 만든다.

## 음악 설정과 캔버스

**BeatGrid**와 **RhythmPattern**은 서로 다른 설정이다. BeatGrid는 분할·강세 묶음·swing 기준이며, RhythmPattern은 실제 note·audio를 갖는 연주다. 상단 **트랙 → 리듬 패턴 만들기**로 패턴을 만든 뒤 글로벌 설정 또는 서클 설정에 배정한다. 개별 리듬을 `재생 안 함`으로 지정하면 해당 서클에서 상속된 패턴도 재생하지 않는다. 패턴은 서클 진입·반복마다 다시 시작한다. BeatGrid 자체는 소리를 만들지 않는다.

템포·스케일·박자·BeatGrid·패턴을 각각 상속/글로벌/개별로 선택한다. 서클에서는 현재 유효 값을 바꾸면 개별 설정이 되고, 같은 값을 그대로 두면 상속이 유지된다. 출처 표시에서 상속이나 글로벌로 되돌릴 수 있다. 스케일을 바꾸면 입력 가이드가 바뀌며 기존 MIDI pitch와 드럼 매핑은 유지된다. 7/8 강세는 `2+2+3`처럼 입력한다. 맞지 않는 강세 합은 재생 준비에서 확인 메시지를 표시한다.

서클의 공간 위치는 곡의 순서를 바꾸지 않는다. 순서를 옮길 때는 캔버스 도구 메뉴에서 **연결선에 섹션 삽입**을 켜고 서클을 연결선 위로 끈다. 전환·분기가 복잡한 연결은 먼저 정리해야 한다. 빈 곳에서 영역 선택하거나 Shift로 다중 선택한다. 캔버스 도구 메뉴와 ⌘G로 정렬·그룹을 만들고 그룹 이름을 두 번 클릭해 접는다. **휠 위는 확대, 아래는 축소**이며 modifier가 필요 없다. 포인터 아래 위치를 기준으로 zoom한다. **⇧+스크롤**, 가운데 버튼 드래그 또는 **이동 도구(H)**로 화면을 옮긴다. **선택 도구(V)**는 서클 선택과 이동을 수행한다. 핀치 zoom도 지원한다. 숫자 배율과 짧은 조작 안내가 캔버스 아래에 표시된다. 캔버스의 확대/축소 버튼은 화면 중심을 기준으로 한다. 이동 도중에는 연속 추종하고 놓을 때만 선택 전체를 한 번 스냅한다. **전체 서클 맞추기(F)**는 모든 서클을 화면 안에 맞춘다.

많은 반복은 최대 56pt 외곽 폭 안에 간격을 좁혀 그리며 숫자를 함께 표시한다. 촘촘한 링은 대비를 낮춰 줄무늬 간섭을 줄인다. 수백 개 링을 기본 배율에서 눈으로 모두 셀 수 있다는 의미는 아니다.

**송폼 / 사운드**는 같은 편집 공간의 두 보기다. 사운드 보기에서 instrument source → effect/bus → 출력 경로를 편집한다. Compressor 입력에 Option으로 연결하면 sidechain이다. 송폼 연결을 두 번 클릭하거나 우클릭 → 연결 편집을 선택하면 `끝부분 안에서(within) / 사이에 삽입(insert) / 겹치기(overlap)`와 길이·리듬·대체 트랙을 설정한다.

## 오디오와 녹음

서클 편집 창의 **오디오 가져오기**로 실제 파일을 추가하고 시작 박·원본 시작 초·길이·Gain·템포 추종을 편집한다. MIDI와 오디오가 공통 시간축에 보이며, 클립을 드래그해서 시작 박을 옮긴다. 원본 파일은 변경하지 않는다. 첫 저장 시 원본 전체를 package 내부 `media/`로 복사한다.

**MIDI 녹음**과 **오디오 녹음**은 선택한 서클의 길이와 반복 횟수에 맞춰 입력을 보관한다. 오디오는 사용자가 허용한 macOS 기본 입력 장치를 사용한다. 반복별 take를 모두 보존하며 마지막으로 녹음된 take를 활성화한다. 편집 창의 **녹음 Take** 메뉴에서 다른 take를 선택할 수 있다. 현재 녹음은 선택 서클을 기준으로 시작하며 count-in·반주 동시 녹음·comping·입력 latency 보정은 제공하지 않는다.

기본 GM Sound Bank 또는 설치된 instrument Audio Unit을 고를 수 있다. Effect Audio Unit은 사운드 노드에서 선택한다. Plugin이 편집 화면을 제공하면 **Plugin 화면 → 설정 적용**으로 state를 곡에 저장한다. Plugin 화면은 현재 사각 편집 창에서 열린다.

0.5.0에서 시스템 오디오 장치 응답 대기가 확인되어 최종 소리 재생·WAV 재출력 검증이 미완료로 남아 있다. 이번 0.7.0은 UI 변경이며, 반복 링·오디오 시간축 geometry·기존 core/휠을 포함한 자동 검증 22개를 통과했다. 실제 창 동작과 저장 결과는 [0.7.0 검증](qa/0.7-review.md), 설계는 [한눈에 보는 서클 편집](docs/12-unified-section-workspace.md)에 기록한다.

## 현재 범위

- 재생과 export는 실제 MIDI·오디오·effect를 render한 동일한 PCM을 사용한다. 실시간으로 바뀌는 전체 DAW engine은 후속 단계다.
- WAV는 stereo 48 kHz / 24-bit, 기본 잔향은 2초다. Clipping을 발견하면 Gain을 낮춘 후 export한다.
- Stem은 source별 경로를 개별 처리한다. 공유 nonlinear effect가 있으면 stem 합과 전체 mix가 다를 수 있다.
- Audio Unit은 현재 앱 process 안에서 실행한다. 모든 외부 plugin의 호환성, crash 격리, plugin delay compensation, Intel Mac과 구형 macOS 실기는 검증하지 않았다.
- Time-stretch는 일정 템포 구간에서 원속도의 0.25–4배다. 가변 tempo map의 audio는 구간을 나누어야 한다.
- 녹음 writer·가상 MIDI 입력은 자동 검증했다. 실제 마이크와 외부 오디오/MIDI 장치의 녹음 품질은 별도 확인이 필요하다.
- Piano roll과 clip 속성 편집을 제공한다. 상세 파형 편집, automation lane, 연속 pattern phase, 전문 mixer·comping은 현재 UI 범위 밖이다.
