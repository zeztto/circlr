## 실제 GUI 동선

1. 앱 시작 화면의 **프로젝트 열기**로 QA 곡을 열었다. 앱 출력 설정 `⌘,`에서 시스템 기본값이 `Scarlett 6i6 USB`임을 읽고, **앱 안에서만** `Mac Studio 스피커`를 선택했다. 시스템 기본 출력은 바꾸지 않았다.
2. `f0r h3r → 접속 · DJ Intro`에서 `서클 추가 → 오디오 가져오기…`로 QA WAV를 1박·새 트랙·이번 사용 범위에 배치했다. UI는 `오디오 1개 가져오기 완료`, 원본 2.000초, revision **r2**를 표시했다. 저장된 import media SHA-256은 입력 WAV와 동일하다.
3. 오디오 궤도 편집기에서 원본 시작 **0.100초**, 끝 **1.800초**로 trim하고 fade in **100ms**, fade out **150ms**를 입력했다. GUI 표시가 원본 구간 **1.700초**와 r3→r6으로 바뀌었다. 분할 위치 **0.800초**에서 `분할`을 누르자 뒤 서클이 선택되고 **0.900–1.800초** 구간, 배치 **2.6박**, r7이 보였다. `⌘Z`는 단일 서클 **0.100–1.800초**와 r8을 복원했고 `⇧⌘Z`는 뒤 서클과 r9를 다시 만들었다.
4. 뒤 오디오 서클의 **오토메이션 → 볼륨**에서 점 2개를 만들었다. GUI의 첫 점은 **1박/−6.00 dB**, 둘째는 **2.5박/0.00 dB**, 적용 체크 상태와 r14를 보였다. `⌘S`의 `저장 완료 · build211-daw-journey.circlr`를 확인했다.
5. `⌘Q` 후 새 앱 세션의 시작 화면에서 같은 저장 곡을 다시 열었다. 뒤 오디오 서클의 **2개 점/1박 −6.00 dB/2.5박 0.00 dB**, 오디오 편집기의 **0.900–1.800초**가 다시 표시됐고 revision은 **r14**였다. 첫 파일 패널에서 행 클릭과 Open을 연속 실행했을 때 `The file “manifest.json” couldn’t be opened because there is no such file.` 경고가 한 번 나왔다. 파일은 디스크에 존재했고, `⌘⇧G`로 같은 `.circlr` 전체 경로를 지정해 다시 열자 정상 복원됐다. 따라서 이 경고를 저장 손상으로 분류하지 않는다.
6. 재열린 곡에서 뒤 오디오 서클의 **바운스**를 실행했다.
