## 이번 변경과 검증

- `AppStore(storageRootOverride:)`로 테스트의 복구·bounce·take 저장 위치를 임시 디렉터리에 격리했다. 기본 앱의 저장 위치는 변경하지 않는다. 새 `CirclrAppTests` 두 개는 실제 AppStore의 `snapshot → inspect → set_notes → Undo`, AI STOP 뒤 **같은 음악 revision**의 늦은 `apply`·`save`·`bounce` 거절, 수락된 bounce job의 commit 거절과 새 turn 편집을 확인했다. 대상 테스트 **2/2 PASS**. 수락 직후 MainActor에서 STOP하므로 실제 PCM 렌더 진행 중·WAV 게시 직전 경합은 검증하지 않았다.

## 아직 열려 있는 경계

`CirclrCodex`는 앱 실행 파일과 연결되지 않았고, AppStore의 trusted gateway에는 인증된 세션 호출자·전용 helper/IPC가 없다. 기존 일반 MCP socket은 AI turn의 lease를 확인하지 않으므로 계정 대화용으로 사용하면 STOP을 우회할 수 있다. [공식 App Server 문서](https://learn.chatgpt.com/docs/app-server)의 command는 experimental·production 미지원이다. 이번 테스트는 계정 로그인·모델 응답·앱 내 대화나 실제 AI 음악 작업의 증거가 아니다.

0.80 출고에는 최종 후보 앱에서 내장 출력 반복 재생과 실제 청취, 짧은 MP4·AV 동기, 완전한 GUI 제작/재열기/바운스, 가로·세로 UI 및 실제 구버전 앱과의 동시 socket QA가 남아 있다. 0.80의 tag와 GitHub Release는 만들지 않는다.
