## 실제 곡 전체 궤도 PNG

앱 GUI에서 QA 사본을 열고 `f0r h3r` 곡으로 들어가 화면을 축소해 **접속 · DJ Intro, 도시의 기억 · Groove, 수평선 · Lift, f0r h3r · Club Chorus, 북쪽의 밤 · Breakdown, 너의 도시 · Final Chorus, 잔상 · DJ Outro** 7개 섹션 전체가 보이는 구도를 만들었다. 실제 앱 창을 CUA로 1440×900에서 720×900으로 크기 변경하고 CUA가 반환한 전체 창 원본 PNG bytes를 그대로 저장했다. 합성·크롭·구버전 캡처가 아니다. 저장된 PNG 자체를 다시 열어 7개 섹션과 창 상단/하단을 눈으로 확인했고 `sips`로 픽셀 크기를 재검사했다.

## 앱 전용 내장 출력과 작은 포트

앱 출력 설정에서 `시스템 기본값: Scarlett 6i6 USB`를 보고 앱 안의 선택만 `Mac Studio 스피커`로 바꿨다. 재생 시작 후 AX는 **00:07.5**에 `마지막 재생 확인 장치: Mac Studio 스피커`와 재생 정지 버튼을 표시했다. 00:16.1/00:29.1의 실제 PNG에서도 재생 중 시계와 Intro 진행 표시가 보인다. 세로 크기 변경 직후 00:24.7을 관찰했다. Stop 클릭 후 AX는 재생 버튼·**00:00.0**·`이전 출력 정리가 끝났습니다` 및 `출력 장치 시작 완료(시작 후 0.1초)`를 표시했다. 격리 bundle UserDefaults의 `circlr.playback.outputDeviceUID`는 종료 후 **`BuiltInSpeakerDevice`**다. 이는 앱의 장치 선택·재생 시계·출력 시작 완료 UI 확인이며 스피커의 물리적 소리를 들었다는 판정은 아니다.

Stop 후 고밀도 `도시의 기억 · Groove` 섹션에서 작은 `오로라 패드 MIDI` 서클을 클릭했다. AX에 `오로라 패드 MIDI · OUT MIDI 연주` 포트 버튼이 나타났다. 서클에서 포트로 가는 공백을 클릭한 뒤에도 AX 버튼이 남았고, 앵커 클릭 뒤 버튼은 `(selected)`가 되며 연결 편집 안내가 보였다. 해당 실제 720×900 창은 `build213-small-port-selected-720x900.png` (SHA-256 `113bc254fde1ec944e36decdb198e26893721c992d4e031f2197aaafafaa9031`)로 남겼다. 연결선을 생성하거나 프로젝트 데이터를 편집하지 않았다. 이 검사는 한 작은 OUT 포트의 smoke이며 반경 44/45/46pt 전수 검사는 build212 별도 기록의 범위다.

종료 후 격리 QA 앱/helper 프로세스는 **0개**, 격리 앱 strict deep 서명은 PASS다. 원본 dist 실행 파일·동봉 demo·QA 사본 해시는 모두 시작값과 동일하다. 읽기 전용 CoreAudio 기본 출력 조회는 검사 전·후 **`AppleUSBAudioEngine:Focusrite:Scarlett 6i6 USB:10000B65:1,2`**로 같아 시스템 기본 출력을 바꾸지 않았다. 구형 Scarlett의 실제 작동이나 최신 macOS 호환성은 이 QA의 결함 근거로 사용하지 않는다. 세부 SHA-256 목록과 프로세스/장치 결과는 `baseline.json`, `final-check.json`에 있다. build213 GUI stems는 반복하지 않았으므로 이 문서로 그 변경의 native 검증을 주장하지 않는다.
