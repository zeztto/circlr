재생 중 선택한 케이블의 편집 도구막대는 팔로우 재개 때 숨겨야 하지만, 기존 코드는 도구막대가 없으면 전면 accent 선도 그리지 않았다. build231은 현재 프로젝트의 가시 케이블 선택을 도구막대 수명과 분리해 최종 캔버스 패스에서 강조한다. 감상 모드와 영상 캡처에서는 편집 accent·끝점 핸들을 그리지 않는다. 독립 리뷰에서 첫 MP4 프레임은 `movieWriter` 대입 전에 캡처된다는 지적이 나와 `movieCaptureDepth`가 0일 때만 편집 표시를 허용하도록 수정했다. [UI 감사](0.80-qa232-ui-density.md) · [계획](0.80-qa232-plan.md).

[독립 읽기 전용 리뷰](0.80-build231-ui-review.md)의 최초 두 지적은 movie 첫 프레임 overlay와 `playing + following`에 대한 단위 테스트 한계다. 전자는 캡처 depth guard·회귀로 해결됐고 재검토에서 새 차단 결함을 찾지 못했다. [격리 native 앱](0.80-build231-native.md)에서는 재생 중 고밀도 섹션의 선택 케이블 강조·AX 패널, 팔로우 재개, MP4 첫 프레임의 편집 표시 제외와 가로·세로 7/7 섹션 화면을 확인했다. 팔로우 재개 뒤 카메라가 곡 궤도로 이동해 해당 로컬 케이블의 지속 픽셀 가시성은 확인하지 못했고, 짧은 MP4에 2-frame 초과 gap 1개가 있었다. 물리 청취·Scarlett 호환성·장시간 영상은 미검증이다. [build230 실제 모델→MCP QA](0.80-qa232-model-native.md)는 이 build231 UI 패키지와 다른 서명 앱에서 실행됐으며 앱 내 계정 채팅이나 제품 build231의 실제 모델 시험으로 전용하지 않는다.

0.80의 다른 열린 DAW·영상·청취 QA가 남아 있어 이 개발 build만으로 정식 tag/GitHub Release를 만들지 않는다.
