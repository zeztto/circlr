# 0.80 Space 재생 단축키 계약

캔버스와 MIDI·step·오디오 편집기의 transport 단축키는 **modifier 없는 Space**만 받는다. Command, Control, Option, Shift, Fn을 누른 Space는 재생/정지를 요청하지 않는다. Caps Lock이 켜진 상태의 일반 Space는 허용한다. 텍스트 편집기(`NSTextView`/`NSTextField`, IME 조합 포함)가 활성화돼 있으면 Space는 입력에 남긴다. 감상 모드의 Fn+Space는 local monitor와 캔버스 keyDown 양쪽에서 macOS로 전달한다.

적용 경로: `AlbumCanvas`, `CircleCanvas`, `StepGridCanvas`, `AppStore.handleMIDIKey`, `AudioLaneView`, `OrbitAudioView`, `MusicEditorWindow`, `ViewingMode`. 다른 키의 편집·이동 단축키는 이 계약의 대상이 아니다.

`PlaybackSpaceShortcutTests`는 plain Space, Caps Lock, 다른 키, 다섯 modifier, 텍스트 입력 상태 및 감상 모드 Fn+Space의 두 단계 통과 판정을 검사한다. `./scripts/swift-local.sh test --filter PlaybackSpaceShortcutTests --scratch-path .build/playback-space-key-tests`로 최종 변경 소스의 앱 타깃을 다시 컴파일한다. Native 검증에서는 미디어 창을 닫은 뒤 ⌥Space가 재생을 시작하지 않는지, 일반 Space는 한 번 토글되는지, Fn+Space와 IME 입력이 보존되는지 별도로 확인해야 한다. 이 문서는 native 결과를 주장하지 않는다.
