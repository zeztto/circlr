build230은 녹음 중 프로젝트 교체가 take를 다른 곡에 적용하지 않도록 막고, MIDI 녹음 시간을 단조 시계로 표시한다. 기존 공개 MCP와 구분되는 **앱 소유 내부 trusted turn**에서는 앱이 이미 연 곡에 `save`, 앱이 선택한 목적지에 `export`를 허용한다. 모델 요청은 경로를 지정하지 못한다. 대용량 프로젝트 저장은 기존 패키지를 건드리지 않은 채 stage를 만든 뒤 revision·문서·AI STOP·목적지를 재확인하고 게시한다. WAV export는 선택 시점의 폴더 identity를 고정하고 기존 이름을 덮어쓰지 않는다. 이는 Codex 계정 로그인·대화 UI의 구현이나 공개 G0 통과가 아니다.
