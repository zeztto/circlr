# 0.10.1 앱 아이콘 검증

검증일: 2026-09-07. 대상: `dist/써클러.app`, version 0.10.1, build 12. 환경: Apple Silicon, macOS 26.5.1 (25F80), Xcode의 Swift·actool·iconutil. 결과: **통과**.

## 범위와 완료 조건

앱 아이콘의 실제 적용과 재현 가능한 패키징을 확인했다. 음악 엔진·캔버스·사용자 프로젝트에는 변경이 없다. 기존 기능의 Swift 80개·Python 3개 및 native 음악 검증은 [0.10 기록](0.10-review.md)에 있으며 이번 아이콘 변경의 테스트 결과와 구분한다.

| 검증 | 결과 |
| --- | --- |
| 생성 원본 보존과 alpha | 1254×1254 RGBA 원본 보존, 네 모서리 alpha 0 |
| 빌드 입력 | 1024×1024 RGBA, 실제 투명 모서리 |
| 크기별 아이콘 | 16–1024px 10개 표현을 ICNS로 생성하고 다시 추출 |
| ICNS 왕복 | 10개 크기와 alpha 일치. 8개는 RGBA 픽셀 일치. 16/32px 1x는 변환 후 RGB 차이가 있어 실제 작은 크기 표식을 육안 확인 |
| native 표시 | 최종 앱 경로를 `NSWorkspace.icon(forFile:)`로 읽어 실제 OS 아이콘 확인. 승인한 Composer 미리보기와 PNG 바이트 일치 |
| 번들 | Info.plist의 IconFile=AppIcon, IconName=Circlr. AppIcon.icns·Assets.car가 빌드 리소스와 바이트 일치 |
| 빌드 | `./scripts/build-app.sh` 성공. 소스에서 별도 app-release 빌드 완료 |
| 서명 | `codesign --verify --strict --verbose=2 dist/써클러.app` 통과 |
| 스크립트 | Python AST parse, `zsh -n` 통과. 임시 디렉터리·리소스 검증·기존 앱 보관·교체 실패 복원 경로 검토 |

## 실제 확인한 표시 문제와 해결

ICNS만 지정한 초기 번들은 macOS 26에서 넓은 밝은 배경 테두리를 추가했다. [초기 OS 표시](generated/0.10.1-icon/macos-resolved-icon.png)에서 확인했다. 같은 PNG를 명명된 Icon Composer 리소스로 컴파일하고 `CFBundleIconName`에 연결해 해결했다. macOS 자체의 얇은 표면 테두리는 유지된다. [최종 OS 표시](generated/0.10.1-icon/macos-final-icon.png).

![최종 앱 아이콘](generated/0.10.1-icon/icon-preview.png)

`iconutil`의 Invalid Iconset과 sandbox 안의 빈 NSWorkspace 이미지는 같은 명령을 서비스 접근 가능한 환경에서 실행해 해결했다. 모든 PNG의 크기·이름·RGBA를 확인한 뒤 환경 차이를 대조했다. 이미지나 앱의 기능 오류를 성공으로 처리한 것이 아니다.

기존 공유 module cache에서는 `circlr_synth_*` 선언을 찾지 못해 release 빌드가 실패했다. 배포용 scratch/cache를 `.build/app-release`로 분리하고 최신 소스 전체를 빌드해 통과했다. 신스 구현은 수정하지 않았다.

native 아이콘 검증은 앱 실행 없이 파일 경로의 표시 아이콘만 읽는다. 사용 중인 앱의 종료·재시작, 사용자 곡 열기, 복구 데이터 변경은 하지 않았다. Dock에서 이미 실행 중인 이전 프로세스의 캐시 갱신은 이번 검증 범위에 없다. 저장 후 ⌘Q로 종료하고 새 앱을 열면 새 번들을 사용한다.

macOS 14/15에서의 직접 표시는 이번 환경에서 검증하지 않았다. 하위 버전용 ICNS와 배포 타깃 14.0의 리소스 생성·번들 포함을 확인한 범위다. 로컬 ad-hoc 서명 검증이며 notarization·App Store 배포 검증이 아니다.

## 최종 검토

`git diff`에 나타나지 않는 초기 untracked workspace이므로 이번 변경 파일 전체를 직접 읽었다. 검토 범위는 `scripts/build-icon.py`, `scripts/build-app.sh`, `scripts/swift-local.sh`, `scripts/package-app.py`, `Resources/Info.plist`와 아이콘 설정이다. 구체적인 출시 차단 결함은 발견하지 못했다. 기존 앱 0.10.0은 `dist/archive/써클러-0.10.0.app`에 보관했다.
