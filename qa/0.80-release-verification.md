2026-09-25 사용자 지시로, DAW 제작과 외부 Codex→MCP의 제한된 실제 동선을 막지 않는 남은 영상 품질 항목은 0.90으로 이월하고 0.80을 정식 출고했다. [출고 gate](0.80-release-gates.md)의 원 판정은 유지한다.

- 게시 시점 `main`, `release/0.80.0`, 원격 `v0.80.0^{}`는 모두 `bd97be9f3c28d7ddc49ca6975ad23aa49aa7c00f`였다. 이 파일을 추가하는 후속 문서 commit은 `main`만 전진시키며 태그·릴리스 브랜치·앱 바이너리를 바꾸지 않는다.
- GitHub API의 최신 Release는 `v0.80.0`, `draft=false`, `prerelease=false`였다. 한영 본문과 ZIP·`SHA256SUMS` 두 자산을 확인했다. ZIP 자산의 GitHub digest와 로컬 ZIP SHA-256은 위 값으로 일치했다.
- 원격 두 자산을 새 임시 폴더에 재다운로드해 `shasum -a 256 -c SHA256SUMS`가 `OK`였고, 내려받은 ZIP과 로컬 검증 ZIP의 SHA-256이 일치했다. 로컬 ZIP의 압축 해제 67개 파일 byte 대조·strict deep 서명·0.80.0/build242·초기 창 시작은 [패키지 QA](0.80-build242-package.md)에 보존한다. 앱 본체 SHA-256은 `6e7f28166c30d9b2e638aa5d13cb94874dc58c6aca3f3f641c7b9d194bd8fa43`이다.
- 사용자 설치 앱과 프로젝트는 교체하지 않았다. build242 실제 QA에서는 시스템 기본 오디오·디스플레이가 불변이었다. 구형 Scarlett 6i6의 현재 macOS 호환성은 검증하지 않았다.

**출고와 별개로 남는 원 판정:** 1080p·10분 MP4의 decoded PTS 최대 70.000ms 한 곳은 사전 ≤66.67ms 기준 **FAIL**이다. 물리 청취, 실제 compositor 표시 FPS, 지각적 중간/끝 A/V 동기, 한글 IME·Fn+Space·대형 목록 지연은 **OPEN**이다. [원본 영상 QA](0.80-build242-performance.md)와 [0.90 이월 계획](../docs/releases/0.90.0.md)을 따른다. 이 항목들은 Release 게시로 PASS가 되지 않는다.
