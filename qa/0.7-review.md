## Native UI 시나리오

검증은 `qa/generated/unified-editor-ui.circlr`에서 수행했다. 화면 이미지는 실제 실행 앱의 CUA screenshot/AX 도구 결과에 있으며 생성 이미지로 대체하지 않았다. 정확한 logical pixel 크기/프레임률/오디오 latency를 계측했다고 주장하지 않는다.

- **MIDI**: 4개에서 새 note 입력으로 6개. 끝 drag로 길이 1.25박 변경, 본문 drag로 beat 9/pitch 69 이동. Delete 후 5개, ⌘Z 후 6개. 최종 package에서 동일 값 검사.
- **Audio**: 기존 clip을 beat 2→4로 drag. 같은 편집 화면의 가져오기에서 실제 `controlled-input.wav`를 추가해 clip 2개 동시 표시. 추가 clip은 beat 8.5, duration 0.3초. 저장 후 media 파일 2개 존재 및 hash 검사. 격자와 audio의 같은 가로 스크롤 확인.
- **트랙/재사용 격리**: 드럼 트랙으로 선택하면 note 0/audio 없음, 악기 1로 돌아오면 note 6/audio 2 유지. 재사용 서클은 기존 note 3/audio 0 유지.
- **설정**: 개별 tempo 96→104→108 BPM. 초기 build에서 같은 값으로 입력칸을 통과할 때 박자가 개별 설정으로 바뀌는 결함을 발견했다. 최종 build에서 박자를 상속으로 되돌리고 4/4와 Swing 0을 그대로 입력/Tab한 뒤에도 상속 유지 확인. 저장 JSON에서 meter/BeatGrid source=inherit 확인.
- **이펙트**: Delay 추가 즉시 같은 화면 하단에 양/Mix 값과 제거 동작 노출. 설정과 timeline을 숨기지 않음. 실제 처리된 소리의 검증과 구분한다.
- **창 크기**: 기본 약 1180×820 생성 창에서 주요 기능 동시 노출. 최소 크기 제약 근처로 resize 시 가로 항목 잘림 없이 외부 세로 scroll로 이펙트 접근. 넓게 resize/zoom한 창도 확인. 테스트 후 적당한 편집 창 크기로 복원.
- **링/포트/그룹**: 반복 1→8에서 포트와 group 경계가 실제 외곽을 따라 이동. 8번째 외곽 부근 drag로 서클 이동 후 ⌘Z로 복원. 변경된 외곽 출력 포트에서 새 서클로 연결 성공, 연결/생성은 undo로 정리. F로 group/링/라벨을 화면에 맞춤.
- **휠**: 최종 build에서 Verse 중심에 포인터를 두고 native scroll up/down, 125%→179%→125%. 포인터 아래 서클 중심 위치 유지 확인.
- **창 수명/키보드**: 편집 창 최소화 후 다른 서클 drag 시 창이 올라오지 않음. 편집 버튼으로 복원하면 제목은 Verse 재사용, note는 3개. Esc 후 H 이동 안내, drag, V 선택 안내, F 전체 보기와 ⌘S 확인.
- **프로젝트 교체**: 편집 창 열린 상태에서 다른 곡 열기. 이전 창이 닫히고 사용자 곡의 main canvas만 남음. 열기 dialog에서 키보드가 처음 수용되지 않아 활성화 후 Go To를 재시도했고 실제 파일 열기 완료를 확인했다.

## 변경 검토

작업 트리가 untracked여서 구현 직전 `qa/preserved/0.6-source-before-unified/`를 보관하고 실제 파일 diff와 새 파일 전체를 순차 검토했다.

1. **상속 불변성**: 동일값 commit은 원본 음악 설정에 변화를 만들지 않게 generic binding과 숫자 필드에서 no-op 처리. native 재현/수정 검증 완료.
2. **선택과 preview**: 서클/트랙 ID에 따라 MIDI·audio view identity를 갱신한다. 새 트랙 추가와 트랙 변경도 선택 note/clip·기존 plugin을 정리하고 미리 듣기를 취소한다. 임시 drag는 mouseUp에 한 번 저장한다.
3. **Audio Unit 대상**: inline 편집 중 악기 종류/descriptor를 변경하면 이전 plugin view를 정리한다. 비동기 로드 완료와 state 적용에서 focus, track/node ID, AU 종류와 descriptor ID를 검사한다. 제3자 plugin GUI의 실기 동작까지 확인했다는 의미는 아니다.
4. **반복 geometry**: 동일 SectionRings를 그리기·포트·hit·group·fit에 사용한다. N개의 ring을 일부 개수로 cap하지 않으며 큰 값의 moiré는 내부 링 대비를 낮춰 줄였다. 외곽 경계와 숫자는 유지한다.
5. **저장 경계**: 기존 schema, ProjectStore, renderer/DSP, 실제 asset bytes를 변경하지 않는다. 샘플은 QA 폴더에만 있고 빈 기본 곡을 대체하지 않는다.
6. **문서**: README/CHANGELOG/architecture를 0.7 기준으로 수정하고 0.6 탭 문서는 이전 기록으로 표시했다.

이번 UI 목표를 막는 확인된 결함은 남아 있지 않다. 0.5의 CoreAudio 대기 문제의 해결 여부, 실제 소리 출력/외부 녹음 장치/모든 third-party AU 호환성은 별도의 미검증 범위다. 성능 수치나 사용자의 미적 만족도를 단정하지 않는다.
