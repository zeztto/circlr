# 0.90 · 반복 경계 정확도

상태: OFFLINE_VERIFIED · 기준 commit `87011d0` · 개발 branch `release/0.90.0` · 앱 build 미생성.

## 범위

R90-02의 100회 offline 경계 검증과 발견된 반복 횟수 표시 오류만 다룬다. 사용자 우선순위에 따라 MIDI hotplug·inspector·녹음 전 take 보존은 이월한다. 물리 장치 청취·native UI·영상 품질의 성공을 주장하지 않는다.

## 재현과 변경

257-frame body, 557-frame tail, 17-frame 시작 offset을 사용해 실제 `AudioQueueLoopChunkReader`에 가변 크기 buffer를 공급한다. 100회 경계를 지나 모든 좌우 sample을 원본 finite render의 독립 overlap 합과 비교하고, 101번째 경계에서 종료해 잔향이 한 번만 나오는지 검사한다. 기대값은 실제 cycle/tail 또는 scheduler에서 가져오지 않는다.

수정 전 새 테스트는 정확한 경계의 iteration 26개 assertion에 실패했다. 예: 6,151 elapsed frames + 17 offset에서 24회여야 하지만 23회를 반환한다. sample·누적 frame·위상·잔향 assertion은 실패하지 않았다. `PlaybackLoopPCM.iteration`은 정수 바로 아래에 있는 오차를 최대 4 ULP, 백만분의 1 sample 이내에서만 보정한다. PCM, position 보간과 scheduler는 변경하지 않는다. 직전/직후 1 frame 및 0.25/0.0001 frame, invalid/extreme 입력도 검사한다.

## 실행 증거

기본 Xcode 도구가 Swift 6.4를 정상 실행하여 이전 license 차단이 해소됐다. 이전 CLT의 테스트 0건은 합격 근거로 사용하지 않는다.

| 실행 | 결과 |
|---|---|
| 전체 baseline `./scripts/swift-local.sh test --scratch-path .build/r90-validation` | 1,340개: Core 726, Audio 447, Codex 54, App 113. 실패 0, 초기 skip 26 |
| helper 경로 지정 후 `TrustedMCPHelperProcessTests` | 11개 PASS, skip 0. 전체 baseline의 미검증 11개를 보완하며 서로 다른 테스트 11개를 추가한 것은 아님 |
| 새 `PlaybackLoopEnduranceTests` 수정 전 | 1개 실행, iteration assertion 26곳 FAIL, exit 1 |
| 최소 수정 후 관련 회귀 | 67개 실행: 64 PASS, 3 native opt-in skip, 실패 0. 새 endurance test PASS, exit 0 |
| 독립 diff 검토 | 새 high-confidence regression 없음. position 보간·극값 Int 변환·기대값 독립성 확인. read-only 검토이며 native 검증 아님 |

helper 실행 환경은 `CIRCLR_TRUSTED_MCP_HELPER_BINARY="$PWD/.build/r90-validation/out/Products/Debug/circlr-trusted-mcp-helper"`였다. 전체 baseline과 helper 보완 후에도 장치/native opt-in 15개는 skip이며, 완료 판정은 범위별 증거로 구분한다.

현재 소스의 집중 검사:

```sh
./scripts/swift-local.sh test --scratch-path .build/r90-validation \
  --filter 'PlaybackLoop|AudioQueuePlaybackBackendTests|PlaybackTransportTests|OutputWorkerProcessTests'
```

원본 로그는 작업 사본의 ignored `.build/r90-validation.log`, `.build/r90-helper.log`, `.build/r90-loop-red.log`, `.build/r90-loop-green.log`에 있다. 후속 패키지는 고정한 최종 소스로 만들고 별도 native 검사·최종 README 화면·서명·배포 검증을 수행해야 한다. 이 기록은 Release gate PASS나 0.90 완료 선언이 아니다.
