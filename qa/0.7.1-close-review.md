## 계약과 범위

메인 창의 빨간 닫기 버튼과 ⌘W는 앱 종료 대신 Dock 최소화한다. 같은 메인 창과 편집 상태를 유지하고 Dock 클릭으로 복원한다. ⌘Q / 써클러 종료는 기존 저장 확인을 거쳐 실제 종료한다. 별도 음악 편집 창의 닫기와 Esc는 해당 편집 창을 닫는다.

변경 파일: `Sources/CirclrApp/MainWindowBehavior.swift`, `Sources/CirclrApp/CirclrApp.swift`, `Resources/Info.plist`, README, CHANGELOG, 이 QA 문서. API/auth/DSP/schema/OS 설정 변경 없음. 작업 트리가 untracked여서 기존 CirclrApp.swift를 qa/preserved/0.7.0-before-close-fix에 보관하고 파일 diff로 검토한다. commit/PR/외부 배포 없음.

SwiftUI의 기존 NSWindowDelegate를 보관/forward하는 bridge가 windowShouldClose만 가로챈다. 마지막 창 종료 시 자동 종료 설정을 끄고, AppDelegate의 reopen에서 동일 메인 창을 deminiaturize한다. 명시적 앱 종료에는 기존 confirmDiscard/stop을 유지한다.

검증: `./scripts/swift-local.sh build`, `./scripts/build-app.sh`, codesign 확인. Native CUA로 미저장 QA 곡의 빨간 닫기 → Dock 최소화 → 같은 PID/내용 복원, ⌘W, 편집 창 닫기/Esc, ⌘Q 취소/실제 종료 및 재실행을 확인한다. 사용자 곡은 보존하고 테스트는 별도 QA 곡에서 수행한다.

## 실제 검증 결과

- Debug build 및 최종 release build 통과. bundle 0.7.1/build 8, ad-hoc codesign strict/deep 검증 통과.
- 최종 PID **79985**에서 ⌘W(16:32:33)와 빨간 닫기 버튼(16:33:05) 모두 `Main close requested; starting minimization` 확인.
- 각각 재열기(16:32:47, 16:33:19)에서 **같은 PID**의 `minimized=true`를 확인하고 동일 서클 1·재생 3회·125% 상태로 복원. 종료 또는 새 프로젝트 생성이 아님.
- CUA의 앱 상태 읽기가 앱 재열기를 발생시켜 화면만으로는 최소화가 유지되지 않는 것처럼 보였다. OSLog의 WindowLifecycle debug 이벤트로 읽기 이전 실제 최소화 상태와 동일 프로세스 복원을 확인했다. Dock 앱 직접 접근은 도구 timeout으로 성공하지 않았으며, 실제 AppKit reopen 이벤트 경로를 검증했다.
- 이전 진단 빌드의 close 직후 `minimized=false`는 최소화 애니메이션 완료 이전 값이었다. 이후 reopen 시 true가 확인됐다. 최종 close 로그는 상태를 성급히 판정하지 않고 최소화 시작만 기록한다. 로그에는 곡 내용이나 개인 데이터를 기록하지 않는다.
- 미저장 QA 곡에서 ⌘Q → 저장/취소/변경 버리기 확인. 취소 후 3회 서클 유지. 다시 ⌘Q 후 QA 변경 버리기 → PID 79708이 사라짐을 확인했다. 실제 종료의 confirmDiscard/stop 코드는 변경하지 않았다.
- 최종 음악 편집 창의 ⌘W 및 Esc는 해당 창을 닫고 메인 캔버스로 복귀한다. 메인 창 최소화 proxy가 편집 창에 붙지 않음을 확인했다.
- 기존 사용자 곡은 이번 수정 전 미저장 recovery가 없었으며 저장 package를 유지했다. 테스트 종료 후 `qa/preserved/2026-09-07-before-unified-ui/사용자 곡.circlr`를 다시 열어 chorus와 섹션 2를 확인했다. QA 곡은 `qa/generated/close-minimize-ui.circlr`에 따로 남겼다.

## 변경 검토

기존 SwiftUI NSWindowDelegate를 보관하고 close 이외의 optional selector는 forwarding한다. bridge를 제거할 때 원래 delegate로 되돌린다. AppDelegate는 메인 창을 weak 참조하며 reopen에서 새 창/새 Store를 만들지 않는다. 반환 false로 중복 reopen 처리를 막는다. File 메뉴에 없던 창 닫기/⌘W를 명시적으로 추가해 현재 key window의 performClose를 호출한다. 기존 데이터/DSP/저장 코드 변경 없음.

Window lifecycle 변경은 AppKit 실동작으로 검증했다. 기존 audio/core suite를 다시 실행했다고 주장하지 않는다. 관련 구현 소스, 최종 바이너리와 증거 hash는 `qa/generated/0.7.1-source-sha256.json`, release 로그는 `qa/generated/0.7.1-build.log`, native 상태 이벤트는 `qa/generated/0.7.1-window-lifecycle.log`에 보관한다.
