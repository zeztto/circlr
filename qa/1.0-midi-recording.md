# 1.0 MIDI 녹음 보존

상태: 자동 회귀 PASS · 독립 재검토 완료 · native 미검증 · 미출고

브랜치 `release/1.0.0`에서 CC64/pitch bend를 수신 채널별 lane과 take로 저장한다. 채널 번호 순으로 첫 채널은 기존 대상을 사용하고 추가 채널은 별도 lane으로 분리한다. 각 반복은 초기 controller 상태를 이어받는다. 빈 마지막 반복도 명시적 MIDI 교체 take로 저장해 이전 반복 노트가 남지 않게 한다.

`replacesMIDINotes`와 `sourceMIDIChannel`은 optional 필드다. 기존 JSON은 nil로 읽고 이전 노트 교체 동작을 유지한다. expression-only take는 기록하지 않은 dimension과 노트를 유지한다. 다른 입력 채널에서 expression만 덧녹음하면 유지된 dimension의 lane 채널로 새 dimension을 맞추며 실제 입력 채널은 별도 metadata에 보존한다.

유효한 녹음을 저장할 때 기존 편집본을 `녹음 전` take로 남긴다. 동일 target·arrangement·use의 동등한 완전 교체 take가 있으면 중복하지 않는다. 저장과 전체 채널의 마지막 take 활성화는 단일 Undo다.

## 검증

- 초기 expression 회귀 RED: 2 failures. 독립 검토 후 dimension 보존 회귀 RED: 6 failures.
- 수정 후 `./scripts/swift-local.sh test --scratch-path .build/r100-validation --filter 'MIDIRecording|RecordedTakeSummary|TakeRecordingEntry'`: Core 7 + App 20 = 27 tests, failures 0, skips 0.
- 최종 로그: `.build/r100-expression-preservation-green.log` (로컬 ignored 증거).
- 채널 분리, 반복 carry·빈 반복, 시간/범위/stale 입력, Undo/Redo, JSON 저장·재열기, 노트만 녹음한 lane의 nil expression, 교차 채널 partial 표현 보존, baseline 복원·중복 방지를 검사했다.
- 독립 검토의 최초 P1 note-only non-synth 재생 회귀와 P2 반대 dimension 삭제, 녹음 전 편집본 미보존을 수정했다. 독립 재검토에서 기존 3건 해소와 추가 actionable finding 없음이 확인됐다. sampler/AU 실제 렌더는 실행하지 않았으며 note-only nil expression 계약까지만 검증했다.

## 남은 1.0 gate

실제 MIDI 장치/음향 출력, native 편집·take 선택 UI, 장치 재연결은 이 테스트의 증거가 아니다. live audition은 여전히 note-only이며 pedal/bend 모니터링을 추가해야 한다. RPN pitch bend sensitivity 수신은 아직 없으므로 현재 기본 범위는 ±2 semitones다. active sustain 렌더링은 기존 내장 신스 지원 범위에 한정된다. 이 제한들을 1.0 출시 완료로 처리하지 않는다.
