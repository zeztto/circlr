build231 실제 모델 QA는 외부 MCP 음악 편집을 입증했지만 앱 내부 AI turn의 STOP을 입증하지 않는다. 현재 콘솔의 실행 중 job `취소`는 공용 `cancelAgentJob`만 호출한다. 내부 trusted job이라면 작업은 취소돼도 lease가 남아 후속 AI 편집을 허용할 수 있다. 콘솔이 취소하는 대상이 현재 trusted turn의 소유 job이면 **lease 철회·전용 socket 폐쇄·소유 job 취소**를 한 번에 수행하고 DAW transport는 유지한다. 일반 MCP job은 기존의 job 전용 취소를 유지한다. 이는 계정 대화 UI를 공개하거나 외부 MCP의 `stop` 의미를 바꾸는 작업이 아니다.

재생 화면은 기본 `곡 팔로우`에서 섹션 내부 케이블을 선택해 일시 중지했다가 재개하면 곡 구도로 돌아간다. 이는 설정된 대상에 따른 동작이다. 버튼이 일시 중지 상태에서도 복귀 대상(곡·섹션·고정)을 이름으로 알려 주도록 하고, 설정·음악 시간·카메라 정책은 바꾸지 않는다. 고밀도 Groove의 **섹션 팔로우**를 명시적으로 선택해 케이블 선택→일시 중지→재개 때 선택선이 실제 화면에 남는지 별도 native QA로 판단한다.

검증은 trusted job의 콘솔 취소 뒤 old socket/lease/늦은 apply·bounce commit 차단, 새 turn의 새 endpoint, 공용 job 취소의 독립성으로 한다. Swift 영향 테스트와 전체 회귀, 새 build 앱·helper·kit 서명, 동일 후보의 가로/세로 및 섹션 팔로우 native 화면을 대조한다. 실제 물리 청취, 구형 Scarlett 호환성, 앱 내부 Codex 계정 대화와 장시간 1080p 영상은 이 수정의 PASS 범위가 아니다. 미해결 0.80 gate가 남으면 tag/Release를 만들지 않고 개발 브랜치 checkpoint로 기록한다.
