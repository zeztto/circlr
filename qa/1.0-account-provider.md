# 1.0 직접 계정 provider 검증

상태: 내부 모듈 구현·관련 자동 검증·독립 보안 검토 완료 · 실제 계정/콘솔 통합 OPEN · 미출고

`CirclrCodex`에 SIWC PKCE·callback·token exchange/refresh/revoke·RS256 ID token 검증과 Responses 모델 목록·SSE를 구현했다. 앱에는 loopback listener와 Keychain 계정 coordinator를 추가했다. 모델 호출이나 실제 인증 없이 fixture transport와 로컬 callback으로 검증했다. 콘솔 입력 및 음악 function dispatcher는 아직 연결되지 않았다.

## 최종 실행

```sh
./scripts/swift-local.sh test --scratch-path .build/r100-validation --filter 'SIWC|ChatGPTAccount'
```

2026-09-30 소스 동결 후 exit 0. `SIWCAuthTests` 6 + `SIWCResponsesTests` 11 + `ChatGPTAccountTests` 12 = **29 tests, 0 failures, 0 skips**. 로그는 ignored `.build/r100-account-frozen.log`다. 선택되지 않은 target의 0-test summary를 별도 성공 증거로 세지 않는다. 새 SIWC/ChatGPTAccount 파일에 대한 compiler warning은 없었으며 기존 다른 모듈의 concurrency warning은 이 작업으로 해결하지 않았다.

- 실제 RSA 서명 fixture와 변조·claims·PKCE/state/nonce·callback client ID 검증.
- UTF-8/CRLF 분할, 크기 상한, 실패/불완전/EOF, 선언된 namespace/function·중복 call ID·arguments 검증. `response.completed` 이전에는 도구 결과를 돌려주지 않는다.
- 실제 URLSession+URLProtocol에서 consumer 오류 및 Task 취소 후 `stopLoading` 확인. 실제 모델 서비스 요청의 증거는 아니다.
- 실제 `127.0.0.1` socket에서 잘못된 state 거부 후 정상 callback 수신, HTTP parser와 timeout, 늦은 로그인/refresh와 로그아웃 경계.
- 한 세션의 갱신 직렬화, 취소된 waiter가 token rotation 저장을 방해하지 않음, 오프라인 보존, 이메일 변경과 실제 subject 변경 구별, 명시적 계정 전환, refresh floor.

## 독립 검토와 조치

보안 검토에서 확인한 변경 가능한 email의 계정 식별 오용을 수정했다. issuer/subject/clientID로 계정을 비교하고 email은 profile metadata로 취급한다. 스트리밍 조기 실패 시 underlying task를 명시 취소하고, 공유 refresh task가 credential 설치·정리를 단독 소유하도록 보완했다. 최종 read-only 재검토에서 추가 actionable finding은 없었다. 이는 실제 서비스 인증이나 배포 보안 인증을 의미하지 않는다.

## 1.0에 남는 조건

실제 사용자 OAuth 승인·eligibility, Keychain 접근 및 앱 업데이트 후 유지, 실제 refresh/revoke, 계정 전환·오프라인 복구를 확인해야 한다. `earliest_refresh_at`의 수용 형식은 [공식 계약 조사](../docs/releases/1.0-account-gate.md)에 명시한 호환 가정이며 live 응답 형식은 미확인이다.

공개 콘솔의 로그인·모델 선택·대화 history와 RunLease function dispatcher, STOP/문서 교체 뒤 쓰기 차단, 실제 음악 결과·Undo/저장 검증은 후속 통합 작업이다. API key나 다른 계정으로 자동 전환하지 않는다. credential은 프로젝트·recovery·activity history에 넣지 않고 기존 Codex 계정 설정을 변경하지 않는다.
