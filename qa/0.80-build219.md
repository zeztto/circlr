build218의 실제 앱 `⌘S` 정지를 피하도록 `FileManager.copyItem` 대신 청크 복사를 도입했고, 1MiB 경계의 바이트 보존 테스트를 추가했다. 그러나 읽기 전용 코드 리뷰에서 source를 blocking `FileHandle(forReadingFrom:)`으로 여는 경우 FIFO 미디어가 writer를 기다리며 멈출 수 있음을 발견했다. build219의 전체 테스트와 패키징은 소스가 바뀌는 동안 중단했으므로 최종 결과로 취급하지 않는다. GUI 앱은 실행하지 않았고 화면도 만들지 않았다. build220에서 비차단 일반 파일 검사를 추가했다.
