## 결과와 범위

1. **AI 내부 socket 가용성:** build234 보안 리뷰의 P2 — 같은 UID의 비인증 slow client가 `AgentSocket` 직렬 accept queue에서 3초씩 기다려 trusted 요청을 지연시킨다. 수신 전 단계의 client 격리·동시성 제한·명시적 종료 계약을 설계하고, slow client를 유지한 상태에서 올바른 요청이 지연 없이 완료되는 실제 Unix socket 테스트를 RED→GREEN으로 통과시킨다. `Sources/CirclrApp/AgentSocket.swift`와 신규 전용 테스트만 수정한다. capability/peer UID·PID, 최대 요청 크기, socket 소유자 보존을 약화하지 않는다. 모델 계정 연결 완료로 표현하지 않는다.
2. **실제 DAW 입력 경로:** [선택 입력 조사](0.80-selected-input-investigation.md)는 이 Mac의 Scarlett뿐 아니라 CalDigit에서도 `startRunning`/`AudioDeviceCreateIOProcID`가 timeout이라 제품의 선택 UID 캡처를 보류했다. [build235 입력 감사](0.80-build235-input-audit.md)는 기본 입력 `AudioRecorder`의 HAL 호출이 반환되지 않으면 10초 timeout 뒤에도 serial queue의 cleanup이 영구 대기하고 재시도할 수 없는 결함을 확인했다. 앱 소유 서명된 입력 child로 기본 입력 장치 접근·CAF writer를 격리하고 start/finish deadline·PID reap·늦은 IPC 거절·CAF readback 뒤 take 반환을 구현한다. 선택 UID는 실제 PCM/권한 검증 전까지 fail-closed다. 시스템 기본 입력/출력·사용자 프로젝트는 바꾸지 않는다.
3. **UI 사용성:** [build235 UI 감사](0.80-build235-ui-audit.md)는 720pt 전체 곡 화면에서 시간 궤도 반지름이 손잡이 표시 조건보다 작아 섹션 순서 변경이 우클릭/단축키에 묻히는 문제를 찾았다. 선택 섹션의 앞/뒤 한 칸 이동을 넓은/compact 선택 도구에 노출하고 기존 `moveSectionOccurrence`·Undo·분기/경계 disabled 계약을 재사용한다. 원의 공간 위치 drag는 음악 순서와 계속 분리한다.
4. **계정 G0:** [OpenAI App Server](https://learn.chatgpt.com/docs/app-server)는 제품 내 지속 대화 경로지만 `codex app-server` 명령과 WebSocket의 production 미지원을 계속 명시한다. [공식 플랫폼 안내](https://developers.openai.com/blog/codex-as-a-platform)와 [Codex SDK](https://learn.chatgpt.com/docs/codex-sdk)는 제품 통합 방향·stable SDK 패키지를 제시한다. SDK 패키지 상태를 공개 macOS 앱의 운영 지원·재배포 승인으로 취급하지 않는다. 앱 소유 오프라인 AI 권한 작업은 계속하되 공개 계정 콘솔은 G0 NO-GO다.

## 가정과 검증

macOS 26.5.1, Apple Silicon, 기본 입력·출력 `Scarlett 6i6 USB`, 별도 `CalDigit Thunderbolt 3 Audio`; 세대와 물리 청취는 미확정이다. 현재 공개 `v0.70.0`, 이번 변경은 0.80 개발 브랜치의 build checkpoint다. 실제 사용자 Codex 계정 대화는 공식 production 지원 G0가 열려 있으므로 사용자 기능으로 표시하지 않는다.

AI 구현은 기존 app-owned helper의 실제 프로세스 테스트와 신규 socket slow-client 통합 시나리오, 전체 Swift/MCP 회귀로 검증한다. 입력 child는 실제 프로세스의 hung start/stop과 안전한 retry·정리, 합성 CAF 성공/검증 실패를 테스트하고 기존 recorder 계약을 보존한다. 이 Mac에서 입력 PCM을 얻지 못하면 실기기 녹음 PASS로 기록하지 않는다. UI 변경은 격리 앱의 700/720/900/1440pt 화면·AX, 실제 섹션 순서/Undo 및 최종 가로·세로 README 캡처를 확인한다. 최종 소스의 release 앱 패키지·arm64·deep strict 서명·Codex kit/데모 hash를 확인하고 독립 보안·코드 리뷰를 받는다. README·CHANGELOG·QA·버전 문서를 갱신해 checkpoint commit/push한다. 릴리스 gate 미통과 시 tag/Release는 만들지 않는다.
