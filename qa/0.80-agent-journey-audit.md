이 작업은 제품 소스, 실제 사용자 곡, GUI와 시스템 오디오 설정을 변경하지 않았다. `release/0.80.0`의 build221 코드를 읽고 테스트했으며, 격리 로그만 `qa/generated/r80-agent-journey/`에 남겼다. QA 앱 프로세스는 확인되지 않았고 오래된 integration-QA socket 파일을 소유한 프로세스도 확인되지 않아 `qa/verify-agent-journey.py`를 실제 build221 앱에 붙이지 않았다. 이 harness는 열린 QA 앱과 Application Support의 작업 사본을 전제로 한다. [기존 build185 기록](0.80-offline-daw-journey.md)은 실제 앱에서 MCP로 MIDI→FX→automation→WAV→bounce→save/reopen을 실행한 증거지만 현재 build의 검증은 아니다.

## 고확신 발견

1. **P1 · 내장 AI 제작 경로 미연결.** `Package.swift:12–13`에서 `CirclrCodex`는 별도 target이며 `CirclrApp` 의존성에 없다. 현재 콘솔 `AgentConsole.swift:128–133`은 명령어 입력이고, `AgentSessionGateway.swift:31–64`는 앱 소유 세션만 호출해야 하는 gateway다. 실제 사용자 Codex 계정 로그인·모델 turn·MCP tool 호출을 앱에서 이어 주는 production 경로가 없다. 외부 MCP로 DAW를 편집할 수 있다는 것과 “앱 안에서 AI와 대화해 음악을 완성”은 다른 인수 조건이다.
2. **P1 · trusted 작업 범위가 DAW 완료 동작을 막음.** `AgentRunLease.swift:61–66`의 허용 method는 `snapshot/inspect/job/apply/bounce`뿐이다. `AgentRunReplyProjection`도 apply/bounce만 승인한다(`:445–463`). 따라서 현재 trusted 경로로는 `save`, `export`, `open`을 할 수 없다. 외부 MCP에는 이 명령이 있지만 같은 UID socket은 trusted Codex 세션이 아니다. 모델에게 외부 MCP를 우회 사용시키지 말고, 사용자 선택 경로 handle·문서 binding·lease commit 검증을 갖춘 각 작업을 추가해야 한다.
3. **P2 · 저장 중 AI STOP 지연 가능성.** 외부 `AgentWorkspace.swift:301–315`의 `save`는 `AppStore` MainActor에서 `ProjectStore.saveSessionReportingCleanup`을 동기 실행한다. 큰 미디어 복사·디스크 지연 중에는 같은 actor의 STOP과 UI 처리에 양보하지 않는다. 이 감사에서 실제 장시간 지연을 재현하지는 않았으므로 지연 *위험*으로 분류한다. 내장 AI 저장을 추가할 때 stage 생성은 worker, commit은 MainActor에서 lease·revision·문서 binding을 재검사하고, STOP 시 stage를 보존/정리하는 경계가 필요하다.

## 다음 구현과 인수 slice

`CirclrCodex`의 검증된 host/coordinator를 `CirclrApp`에 연결하는 작은 수직 slice를 먼저 만든다. 명시적인 앱 소유 workspace와 turn이 trusted socket capability를 발급하고, 콘솔 입력→모델 응답→선택된 section MIDI 편집→inspect/Undo→bounce 완료·job 조회→AI STOP 뒤 늦은 쓰기 0건을 실제 QA 앱과 격리 Codex 상태로 검증한다. 이어 사용자 선택 경로의 `save/export`를 lease 범위에 추가하고, stage/commit와 재시작 보존을 시험한다. 마지막으로 외부 MCP의 build221 연속 QA를 `qa/verify-agent-journey.py`로 새 `.circlr` 사본에 실행해 WAV header·nonzero PCM·미디어 hash·원본 불변을 확인한다. 실제 모델/계정, 앱 단독 설치, 물리 청취와 macOS 폴더 권한은 각각 독립 게이트로 남긴다.
