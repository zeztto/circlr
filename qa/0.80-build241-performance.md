## compositor 경계와 정리

`Core Animation FPS`는 이 macOS 26에서 `Disabled because macOS does not have an FPS metric for Core Animation`이다. `Frame Lifetimes` export의 `display-surface-swap`에는 swap 시각이 있으나 앱 PID가 없고 `hitches-updates`의 앱 PID 행은 전체 프레임이 아니다. 내부 `frameCount`, movie FPS, display 전체 surface 집계를 **앱별 compositor-present FPS**로 부르지 않는다. 이번 monitor의 `windowOccluded`는 **20/20 true**였으므로 60초/20초 가시 A/B는 실행하지 않았다. CGWindow에서 QA 창은 1600×932pt·onScreen=true였지만 앞쪽 Dock 전체 화면 layer20, `ChatGPT Computer Use` 126×126 overlay, 때로 Chrome/Guitar Pro가 있었다([창 상태](generated/r80-build241-performance/window-state-during-soak.json)·[겹침](generated/r80-build241-performance/occluders-during-soak.json)). PID 대상 `activateAllWindows` 직후에도 앱 자체 occlusion flag는 true였다. 표시 성능 gate는 **OPEN**이며 MP4 인코딩 FPS와 별개다.

정상 `⌘Q` 후 미저장 QA 데모 변경을 버렸다. 이어 CUA state 조회가 전용 앱을 한 번 자동 재실행해 PID `39148`·새 socket inode `25803855`가 생겼으므로, 빈 startup 창에서 다시 `⌘Q`만 보내 종료했다. 최종 QA 앱/helper PID **0**, 전용 socket **없음**, `lsof` holder **0**, 원본 앱 서명·실행 파일 해시 불변이며 시스템 기본 입출력/화면 설정도 불변이다([종료 전](generated/r80-build241-performance/endpoint-before-quit.json)·[최종](generated/r80-build241-performance/endpoint-after-final-quit.json)). 다른 실행의 socket은 건드리지 않았다.

후속 재측정은 사용자 작업 화면과 분리된 가시 display/Space에서 QA 창 `windowOccluded=false`를 먼저 확보하고 같은 곡·구도에서 앱별 compositor timestamp를 얻을 수 있는 계측 수단을 확정해야 한다. 파일 간격 3곳은 원인별 signpost/캡처·encode 타임라인과 대조하되 추정 수정 없이 재현 여부를 확인한다.
