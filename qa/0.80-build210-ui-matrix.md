Git 제외 로컬 `qa/generated/r80-build210-ui-matrix/`에 패키지 정보와 종료 후 격리 확인 파일을 보존했다. 시작 시 원본 실행 파일 SHA-256은 `90a84563c922da8c2a687aacbbbec93deb4177d563613cf225b98f730276165e`였다.

창은 실제 앱 화면에서 우하단을 drag해 1280·900·700pt로 맞췄고, CUA 창 캡처의 JPEG 치수를 읽어 확인했다. 화면과 AX tree를 직접 검사했지만 이번 창 캡처는 파일로 내보내지 않았다. 수치와 상태의 원자료는 Git 제외 로컬 `qa/generated/r80-build210-ui-matrix/`에 있다. 특히 `loop_initial.json`, `loop_refit.json`, `selected_cable_playing.json`, `stopped_final.json`, `playing_prezoom.json`, `playing_zoomed.json`의 camera·label·output 필드를 비교할 수 있다.

QA 앱에서만 `Mac Studio 스피커`를 선택해 반복 재생했다. 시스템 기본 출력 UID는 시작·종료 모두 `AppleUSBAudioEngine:Focusrite:Scarlett 6i6 USB:10000B65:1,2`였다. QA 앱의 Play를 정지하고 저장되지 않은 **QA 데모 변경만** 버린 뒤 종료했다. 종료 후 QA 앱/helper 프로세스 0, QA 복사본의 strict deep codesign 통과 및 실행 파일 hash 불변을 확인했다. 기존 build187 QA 앱과 사용자 저장소는 조작하지 않았다.

build210 출고 판정에서 hover 복구와 동일 섹션 전후 zoom 비교는 **OPEN**이다. 다음 native QA는 `mouseMoved`를 직접 발생시키는 입력으로 숨은 FX 원을 가리킨 뒤, 동일 섹션 루프·동일 camera·동일 선택 상태에서 label 변화를 캡처해야 한다. 700×1000pt처럼 900pt보다 높은 창과 실제 물리 청취도 이번 검사 범위 밖이다.
