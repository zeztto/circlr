첫 시도 당시 QA 프로젝트의 `manifest.json`은 실제로 존재했다. QA 상위 폴더에는 `manifest.json`이 없다. `row-click-unselected.ax.txt`와 원본 `row-click-unselected.png`가 무선택 상태를, `row-click-alert.ax.txt`/`.png`가 해당 경고를 보존한다. `recent-folder-unselected.ax.txt`, `absolute-selected.ax.txt`/`.png`, `manifest-file-selected.ax.txt`, `manifest-file-alert.ax.txt`/`.png`가 비교 조건이다. File 메뉴에는 `Open Recent` 항목이 없었다. 여기서 Recent Places는 최근 **폴더**이며 최근 프로젝트 파일 목록은 아니다.

앱 콘솔 AX의 시각별 기록은 **08:35:45 missing → 08:37:34 열기 완료 → 08:38:20 missing → 08:38:43 파일 선택 오류**다(`app-console-final.ax.txt`). 격리 앱 PID 86829의 macOS unified log는 `app-unified-final.log`에 보존했다. 그 로그와 앱 콘솔은 `NSOpenPanel.url` 또는 `ProjectStore.load`에 전달된 URL을 출력하지 않는다. 따라서 무선택 시 **실제 `panel.url`이 QA 상위 폴더였다고 단정하지 않는다**. 소스상 `AppStore.open`은 패널이 반환한 URL을 `ProjectStore.load`에 넘기고, `ProjectStore.load`는 그 URL 뒤에 `manifest.json`을 붙인다. 이 소스 경로와 선택/경고 관찰은 맞지만 정확한 내부 URL과 행 클릭이 선택으로 확정되지 않은 이유는 추가 계측 없이는 미확정이다.

`baseline.json`과 `final-check.json`의 SHA-256 대조에서 배포 실행 파일, QA 실행 파일, 동봉 데모 **7/7개 파일**, QA 사본 **7/7개 파일**이 전후 동일하다. 양쪽 앱의 `codesign --verify --deep --strict`는 통과했다. 읽기 전용 CoreAudio 조회에서 시스템 기본 출력은 관찰 중·종료 후 모두 같은 Scarlett 6i6 장치였다. 종료 후 `circlr` 앱 PID와 관련 helper는 0개다. 이 검사는 Open 패널의 오류를 확인하며 수정 여부나 일반 사용자 마우스 동작 전체를 판정하지 않는다.
