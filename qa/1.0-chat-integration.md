# 1.0 콘솔·음악 도구 연결

상태: 자동 통합 검증 PASS · 독립 보안 재검토 완료 · 1.1 이월 · build244 native QA 미실시 · 미출고

기존 하단 콘솔의 명령/AI 모드에서 계정 연결·모델 선택·스트리밍 대화·중단을 사용한다. MIDI 편집, 선택 문맥 조회, 바운스와 작업 확인, 사용자가 이미 선택한 프로젝트 저장을 앱 발급 RunLease로 연결한다. 쓰기 revision은 모델이 관찰한 값을 그대로 검사하며 모델에 경로·권한 발급 기능을 주지 않는다.

## 자동 검증

```sh
./scripts/swift-local.sh test --scratch-path .build/r100-validation --filter 'ChatGPT|SIWC|AgentRunLease|TrustedAgentGatewayIntegration|TrustedAgentIngress'
```

2026-09-30 exit 0. Core 23 + Codex 17 + App 25 = **65 tests, failures 0**. 로그: `.build/r100-chat-integration.log` (ignored). 실제 AppStore의 MIDI 변경→Undo, stale revision 거절과 초안 유지, STOP을 무시하는 늦은 provider 응답, 문서 교체·로그아웃, 잘못된 note/path, turn 전체의 중복 call ID 거절, 6회 도구 반복 한도, 기존 gateway/ingress 권한 검사를 포함한다. 로고의 native SVG 로드도 별도 테스트했다.

독립 검토의 round 간 중복 call ID 재실행 문제를 turn-wide 검사로 수정했다. 새 request ID를 만들더라도 같은 call ID는 재실행하지 않는다. 수정 후 추가 actionable finding은 없었다. 계정 provider의 별도 한계는 [provider QA](1.0-account-provider.md)를 따른다.

## 아직 완료하지 않은 1.0 범위

실제 계정 승인·실제 모델의 음악 도구 호출은 실행하지 않았다. 현재 앱 내 도구는 MIDI/바운스/현재 프로젝트 저장 중심이며 FX·automation·음색·전체 송폼 편집 도구 확장이 남는다. 이를 R100-05 전체 완료로 표시하지 않는다. 계정 연결은 명시적 사용자 동작에서 준비하며 QA와 배포 bundle의 Keychain service를 분리한다.

후보 패키지의 화면·키보드·가로/세로 검증 및 새로운 실제 스크린샷은 아래 후속 기록에 추가한다. 기존 0.90 스크린샷을 build244 근거로 사용하지 않는다.

## 2026-09-30 작업 종료 결정

사용자의 마감 우선 지시에 따라 이 신규 기능의 추가 구현과 native QA를 중단한다. 자동 검증 결과는 유지하며 미검증은 완료로 바꾸지 않는다. [1.1 계획](../docs/releases/1.1.0.md)으로 이월했다. build244를 정식 출고하지 않는다.
