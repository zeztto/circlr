## 악기·이펙트·음악

엔진 2는 velocity 반응이 있는 harmonic keys, mono bass, PolyBLEP saw, TPT SVF, 공명·폭·필터 envelope와 voice stealing carry를 사용한다. 기존 patch/효과의 버전 누락은 이전 렌더 알고리즘을 선택한다. 새 reverb는 pre-delay, 저역 정리, comb와 all-pass 확산을 사용한다.

SynthQualityTests 6개에서 이전 버전 decode, 저역 mono, 타건별 spectrum 변화, 70노트 voice pool, 64/1024 block 결과 일치, 높은/낮은 음역과 극단 resonance의 유한 출력, release와 reverb 감쇠·밀도·stereo, effect chain 처리 예산을 검사했다. C의 `-Wall -Wextra -Werror -fsyntax-only` 검사도 통과했다. 자동 검사가 alias·클릭·음색 품질에 대한 포괄적인 청취 검사를 대체하지 않는다.

f0r h3r v2는 116 BPM, F♯ minor, 68마디, 11섹션, 9트랙, 3,119개 노트이며 142.689667초다. 주 모티프·후렴 응답·마지막 해결구, 낮아진 코드/리드 음역, 별도 킥 sidechain, 개선된 코드 voicing과 잔향을 반영했다. 보유 Splice 6샘플을 사용했고 추가 지출은 0 credits다.

`qa/analyze-song.py`는 BS.1770-5 stereo K-weighting과 gates를 사용하며 997Hz calibration 및 silence 검사를 통과했다. 자체 측정기로 인증 계측기라는 의미는 아니다. [분석 결과](../music/f0r-h3r/v2/audio-analysis.json), [제작·튜토리얼](../music/f0r-h3r/v2/README.md).

## 영상·장치 경계

CanvasMovieWriter 테스트는 서로 다른 픽셀 프레임을 H.264로 인코딩하고 다시 decode하여 변화가 유지되는지, 320×240·0.5초 영상과 AAC 오디오 track/RMS, 기존 파일 보호, staging 정리와 취소를 확인한다. 실제 서클이 움직이는 녹화, 최소화 중 프레임 지속, 음악 끝 동기, 종료 대기는 현재 실제 장치에서 완료하지 못했다.

출력 조사에서 기본 장치는 Scarlett 6i6 USB / 44.1kHz였다. `AVAudioEngine.mainMixerNode` 초기 연결과 DLS 미리 듣기가 CoreAudio HAL 호출에서 지연됐다. 취소 뒤 늦은 note-off가 장치를 다시 여는 경로를 고치고, offline AU 설정을 노드 연결보다 먼저 수행하며, 실제 출력 연결은 background에서 한 번 시도하고 10초 뒤 오류를 알리도록 했다. OS 내부에서 멈춘 호출 자체를 강제 종료하지 않는다.

사용자에게 Mac Studio 스피커로 잠시 변경 가능한지 요청했으며 시스템 출력 설정은 임의 변경하지 않았다. 다음 검증은 내장 출력에서 실시간 테스트와 10–20초 실제 녹화·최소화·중간 정지·파일 decode를 마친 뒤 Scarlett 장치 복구/hot-plug 시나리오로 돌아가는 것이다. 9트랙 전체 길이의 모든 stems를 동시에 유지하는 메모리 한도도 향후 스트리밍 export 과제로 남는다.

## 패키지와 배포 범위

`dist/써클러.app`은 0.13.0 build 15이며 이전 번들을 `dist/archive/`에 보존했다. 실제 native QA 앱과 배포 앱, release binary의 Mach-O UUID는 모두 `362910B0-FA93-37AF-B67B-A7DB33BF9590`이다. 아이콘과 키트 25개 파일 hash가 원본과 일치하고 strict 로컬 서명 검사를 통과했다. notarization 또는 범용 macOS 배포 인증을 받은 것은 아니다.

사용자가 승인한 `zeztto/circlr` private 저장소에는 소스·문서·테스트·아이콘·직접 작성 MIDI만 보관한다. licensed audio/곡 프로젝트, build 앱, 인증정보와 로컬 설정은 제외한다. Git 이력 및 최종 진행 상태는 [진행 기록](0.13-progress.md)을 따른다.
