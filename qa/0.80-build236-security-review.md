앱이 발급한 lease에 `save`가 있을 때만 helper의 목록·호출에 저장이 나타나며, `export`는 앱이 정한 WAV 목적지가 함께 있어야 나타난다. 모델이 제출한 파일 경로·socket·capability는 파일 작업 권한이 아니다. 실제 child 테스트는 비허가 메서드, 문서 교체, STOP 이후 늦은 게시와 자식 종료를 검사했다. 전체 회귀의 해당 child 테스트 11개가 skip 없이 통과했다. [통합 QA](0.80-build236.md).

이 검토는 공개 계정 연결 경로의 보안 승인이나 macOS 저장 패널에서 사용자가 실제 목적지를 선택하는 GUI 동선을 입증하지 않는다. `codex app-server`의 production 지원, 로그인·계정 격리, 사용자 승인·중단·재개, end-to-end 실제 모델 작업은 [1.0 계획](../docs/releases/1.0.0.md)의 G0/R100-03~05에 남는다. 이번 변경은 오프라인 앱 소유 helper의 범위 제한으로만 판정한다.
