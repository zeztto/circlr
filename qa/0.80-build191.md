## 실제 앱 관찰

1. 접근성 트리의 `버전 0.80.0 · 빌드 191`과 `f0r h3r 열기 완료`를 확인했다. 곡→`접속 · DJ Intro`로 이동했을 때 먼 FX 위성이 중심 궤도의 크기를 강제로 축소하지 않았다. 가까운 MIDI·악기·효과 서클과 섹션 IN/OUT이 한 화면에 표시됐다.
2. 앱 창을 약 **808×900**, 이어 약 **700×900**으로 줄였다. 상단 주요 조작은 두 줄로 배치되어 겹치지 않았고 선택 섹션의 중심과 IN/OUT은 캔버스에서 읽을 수 있었다. 900/1280pt 및 실제 별도 세로 디스플레이는 이 실행에서 확인하지 않았다.
3. 약 808pt 창에서 `P`는 `접속 · DJ Intro · IN 재생 경로`를 선택했고, 접근성 selected 상태·화면의 포트 표시·작업 도구를 확인했다. `Tab`은 OUT으로 이동했고 IN/OUT 모두 화면 안에 남았다. 축소 버튼을 두 번 눌러 보통 포트가 숨는 배율로 만든 뒤 `P`를 누르자 선택 포트가 표시되고 카메라가 편집 가능한 크기로 복원됐다. 정확한 44/45/46px 경계는 Core 테스트 계약으로만 확인했다.
4. **FAIL:** 선택한 섹션 포트에서 `Return` 또는 작업 도구의 `연결 편집`을 실행하면 도구가 닫히지만 인라인 연결 편집기가 열리지 않았다. `showConnections()`는 `focusHierarchy(detail:true)`를 요청하지만 `AlbumCanvas.focus`가 음악 이외의 궤도를 overview 카메라로 돌려 서클이 editor 표시 기준 325px에 못 미친다. 이 결함은 후속 빌드에서 다시 검증한다.
