## 검토와 해결한 문제

작업 트리는 untracked 상태여서 git diff가 제공되지 않는다. 변경 파일 전체와 기존 0.5 동작 기록, 실행된 QA 시나리오를 기준으로 검토했다.

1. NSHostingView를 원 내부에 넣는 코드와 확대 포커스 경로를 제거했다. 별도 창은 동일 AppStore를 공유하며 다른 프로젝트 사본을 만들지 않는다.
2. source/track 변경 시 PianoRoll identity를 바꿔 이전 note drag preview가 새 대상에 적용되지 않게 했다. 사용자 MIDI와 audio 파일을 덮어쓰는 초기 예제 데이터는 없다.
3. 자동 창 활성화, 최소화 해제, 반복 close 호출, 닫힌 뒤 main window focus 유실을 발견하고 수정했다. Esc와 메인 H/V/F/첫 drag는 최종 빌드에서 재검증했다.
4. root ViewBuilder의 maxHeight가 tab row에도 적용되어 큰 여백이 생기던 오류를 VStack으로 수정하고 실제 넓은 piano roll 렌더를 확인했다.
5. 캔버스의 기존 group delta snap, model/view 분리, undo, 재생 generation guard는 유지한다. 새 wheel 함수는 유한값·범위·커서 고정·natural-scroll 정규화 검증을 포함한다.

확인된 새 차단 결함은 남아 있지 않다. 서드파티 plugin UI와 실기 마이크, 최종 audio 재생은 통과로 표시하지 않는다. 0.5에서 확인된 CoreAudio 응답 대기의 현재 해결 여부는 이번에 다시 확인하지 않았으며 OS 서비스를 재시작하지 않았다.
