# 0.80 build192 · 재생 중 MIDI 편집과 저장 재열기

상태: **해당 native 동선 PASS / 0.80 출고 승인 아님** · 2026-09-23. 격리된 `com.circlr.portfocusqa` 0.80.0/build192 앱과 새 QA 작업 사본만 사용했다. 시스템 기본 출력 `Scarlett 6i6 USB`는 바꾸지 않고 앱 전용 `Mac Studio 스피커`를 사용했다. 실제 소리의 청취 품질은 판정하지 않았다.

1. 앱 시작 화면에서 동봉 `Invention 8 · 대화하는 궤도`를 열었다. 첫 섹션 `주제의 출발`의 `빛의 플럭 MIDI` 궤도에서 첫 F4 노트(beat 0.5, 길이 0.5, pitch 65, ID `0167053F-23A0-5A1B-85E8-F6C9D4FAC6F2`)를 선택했다. 노트 세기는 127이었다.
2. 섹션 루프를 켜고 Play했다. 접근성 상태에서 `재생 중`, 재생 시계 진행과 `섹션 루프 · 8회`, 마지막 확인 장치 `Mac Studio 스피커`를 확인했다. MIDI 편집기가 열린 채 세기 필드에 100을 입력해 Return으로 적용했다. 같은 노트 버튼과 필드 모두 `세기 100`으로 바뀌고 프로젝트 revision은 0→1이었다. 앱은 `편집 내용은 다음 재생에 반영됩니다`라고 표시했다. 이 시험은 재생 중 반영된 *소리*를 측정한 것이 아니다.
3. Stop 후 앱은 출력 정리 완료를 표시했다. `⌘S`로 `~/Library/Application Support/circlr-portfocus-qa/build192/r80-build192-bach-live-edit.circlr` 사본을 저장했다. 저장 manifest SHA-256은 `f7db7dc2a7aab57323b74f6a353c9fd4a996dcb967bb0edf8b0c4165fd96734f`다. JSON에서 `musicRevision=1`과 위 note ID의 `velocity=100`을 독립 확인했다.
4. 앱을 닫고 시작 화면의 `프로젝트 열기…`에서 사본을 선택해 다시 열었다. `Invention 8 · 대화하는 궤도 열기 완료`, 76개 노트, 같은 F4 노트와 세기 100이 표시됐다. 첫 선택 시 파일 행이 실제로 선택되지 않은 상태에서 Open을 눌러 `manifest.json` 없음 오류가 한 번 나타났다. 절대 경로로 행을 선택한 뒤 재시도하자 정상 열렸다. 이는 선택 실수로 기록하며 저장 파일 결함의 재현으로 간주하지 않는다.
5. 재열기 뒤 다시 Play했다. 이 두 번째 재생의 루프 메뉴는 `off`였으므로 반복 검증으로 세지 않는다. 재생 중 같은 노트를 100→90으로 변경(revision 2), `⌘Z`로 100 복구(revision 3), `⇧⌘Z`로 90 재적용(revision 4)했다. 재생 시계가 계속 진행했고 편집기는 보였다. 다시 Undo로 100(revision 5)을 복구하고 Stop하자 출력 정리가 완료됐다. 이 두 번째 세션의 임시 변경은 QA 사본에 다시 저장하지 않았다.
