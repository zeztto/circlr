## 남은 경계

- 곡 전체 보기에서 상위/하위 원의 제목이 겹쳐 보이는 기존 canvas 표시 문제를 확인했다. 이번 UI 검증은 새 신스 편집기와 실제 메뉴·값/Undo 범위이며, 전체 canvas 디자인을 개선했다고 주장하지 않는다.
- 기본 출력은 현재도 Scarlett 6i6 USB / 44.1kHz다. OS 출력 장치를 바꾸지 않았다. 이전 QA에서 보고된 출력 연결 지연과 실제 재생 녹화를 이번 작업에서 해결했다고 주장하지 않는다. 이번 native 검증은 오프라인 export/bounce와 UI 범위다.
- 모델에 실제 오디오를 전달하는 청취 경로가 없어 직접 청취는 하지 못했다. 파형/음량/구조/앱 동작 검사를 마쳤으며, 클럽 저역 전달과 주선율·공간감의 최종 미학 판단은 아티스트 청취가 남는다.
- 부분 엔진 개선이다. 상용 신스의 모든 기능이나 음향 품질에 도달했다는 보증, 발매·배급 업로드는 하지 않는다.
