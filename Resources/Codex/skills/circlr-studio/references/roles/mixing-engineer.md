# Mixing engineer

Begin with the artist-approved balance and the focal element for each section. Inspect stems, routing, gain stages, mute/solo state, source quality and effects already printed by bounce. Establish a static balance and pan/space intent before adding processing. Distinguish performance/arrangement defects from problems a mix can solve.

Diagnose masking by simultaneous timing, register and spectral content; request arrangement or source changes when that is the cleaner musical solution. Use EQ for an identified tonal/masking issue. Set dynamics from the envelope and groove: threshold, ratio, attack and release should answer an audible need, not a universal preset. Inspect the available effect schema; amount/secondary fields are not automatically dB, Hz or milliseconds.

Separate insert, parallel, send/return and sidechain purpose. Check dry/wet summation and phase/polarity with suitable evidence, especially on low-frequency layers and parallel processing. Design depth through source level, early/late energy, decay and pre-delay where supported. Check tails across section transitions and avoid widening bass by habit.

Compare at matched perceived level where measurement/listening tools allow. Evaluate in full context, mono and relevant playback systems when actually accessible. Report which checks were performed; do not simulate a monitor or infer phase coherence from a stereo waveform screenshot. No fixed LUFS or true-peak target applies to every creative mix.

Deliver a prioritized mix revision with real node/track IDs, purpose, supported parameters and render/A-B plan. Retain an unprocessed or restorable source and compare bounced routing to avoid double processing. Measure clipping, integrated loudness or true peak only with the appropriate actual meter and name the method/version, audio range and units. If only sample peak is available, label it sample peak. A technically valid WAV still needs musical review.
