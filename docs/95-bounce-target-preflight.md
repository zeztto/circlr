# 바운스 대상과 연결 사전 검사 — build80

문제: MIDI·오디오·출력·이펙트 편집기의 바운스 버튼은 대상 이름이 없었고, 입력 없는 출력이나 중복 출력을 실제 렌더 후에 거절했다.

계약: 공통 버튼에서 트랙 이름을 표시하고 문제는 비활성 버튼/도움말에 알린다. 바운스는 이번 섹션 사용의 트랙 출력 앞 경로를 캡처하며 출력 레벨/오토메이션·전역 처리는 그대로 둔다. UI·MCP·최종 적용은 동일한 Core target 검사를 사용한다. MCP는 실패 시 job 생성 이전에 거절한다. 최종 적용 시에도 다시 검사한다. 원본 음표와 노드는 보존한다.

검증 계획: 정상/없는 트랙/연결 없음/중복 출력/다른 arrangement, native 버튼 대상·오류·실제 바운스·원본 복원·Undo 및 음악 보존. 작은 창 가시성을 확인한다. 물리 I/O를 시작하지 않는다.

결과: 관련17개 테스트, release63.73초, native7상태와 실제 바운스·원본 복원·Undo/재열기·MCP job 생성 전 거절·음악/패키지 비교 통과. [QA](../qa/bounce-target-review.md).
