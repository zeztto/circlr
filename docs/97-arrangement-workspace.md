# 편곡안 생성·이름·전환 작업 공간

목표: 같은 곡의 구성을 바꿔볼 때 곡 설정 아래로 이동하지 않고, 편곡안 목록에서 이름을 정해 복제하고 구분해서 전환한다. 별도 고정 패널을 추가하지 않는다.

## 사용자 동선

1. 곡·섹션·MIDI 등의 상단 현재 편곡 표시 또는 ⌥⌘J로 목록을 연다.
2. 현재 재생 편곡을 확인하고 이름 변경(⇧⌘N) 또는 이름을 정한 복제(⇧⌘D)를 선택한다. 이 단축키는 목록에서만 작동한다.
3. 같은 목록 안에서 이름을 입력하고 적용한다. 입력 중 다른 안 적용은 막으며 Esc/취소는 이름 입력을 취소한다.
4. 복제한 안은 같은 곡에 추가되고 재생 편곡이 된다. 목록을 갱신해 새 이름을 즉시 확인한다.
5. 기존 검색·번호 구분·현재 안 재선택 no-op·Undo/Redo·저장을 유지한다.

## 데이터 계약

- 복제 대상은 요청에 고정한 compositionID와 currentID다. 다른 도구가 activeArrangementID를 변경해도 다른 곡을 복제하지 않는다.
- 소유 곡·편곡 참조·프로젝트/편집 세션을 검증한다. 녹음·렌더·import 등 충돌 상태와 오래된 요청은 적용하지 않는다.
- 이름은 공백을 제거한 1–120글자다. 동명은 허용하며 #번호로 구별한다. 같은 이름으로 변경하면 이력을 추가하지 않는다.
- 복제는 새 arrangement/use/flow-edge/group ID를 생성하고 해당 참조를 맞춘다. 해당 section/music/group의 사용자 색상도 새 주소에 복사한다. 원래 안과 다른 곡·트랙·자산은 보존한다.
- 섹션 원본은 공유한다. 이번 사용의 override는 별도로 바꿀 수 있으나 공유 원본 편집은 여러 안에 반영된다. 이 차이를 복제 입력에 표시한다.
- 편곡안 삭제·실시간 A/B 청취·전체 곡 복제는 이 작업의 기능으로 표시하지 않는다.

## 검증 기준

현재 이름 표시, 키보드 이름 입력/취소/적용, 복제와 원안 전환, 동명 no-op, 빈 이름 거절, 다른 곡 보존, 오래된 요청 거절, 한 번의 Undo/Redo, 대안의 이번 사용 automation 분리, 저장/재열기를 검증한다. 작은 창과 긴 이름에서 조작이 잘리지 않아야 한다. 실제 청취 품질과 장치 안정성은 별도 조건이다.

## MCP

`apply.operations`의 `duplicate_arrangement`와 `rename_arrangement`는 명시적인 `compositionID`, `arrangementID`, `name`이 필요하다. 기존 projectID/expectedRevision 검사를 사용하고 일괄 요청은 전부 성공하거나 반영하지 않는다.

MCP 복제는 새 안만 추가하고 현재 재생 편곡과 편집 화면을 보존한다. UI에서 직접 복제할 때 새 안을 선택하는 동작과 다르다. 생성된 ID는 다음 snapshot의 소유 목록에서 확인한다. 전환하려면 `select_arrangement`에 `compositionID`와 `arrangementID`를 명시한다. 이 작업은 재생 편곡과 활성 편곡을 의도적으로 전환하므로 현재 편집 경로가 바뀔 수 있다. 앱 내장 Codex kit에도 같은 schema를 포함한다.
