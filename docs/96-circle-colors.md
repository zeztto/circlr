# 서클 종류별 색상과 사용자 지정

서클 테두리·궤도·음악 표시에는 종류별 기본색을 사용한다. MIDI 민트, 오디오 블루, 이펙터 코럴, 곡·악장 바이올렛, 섹션 앰버, 악기 틸, 앨범 로즈, 그룹·출력 실버다. 배경과 글자는 기존 다크 테마를 유지한다.

서클 우클릭 또는 캔버스에서 C로 서클 메뉴를 열고 **서클 색상**을 선택한다. 종류별 기본값, 8색 팔레트, macOS 사용자 지정 색상 선택기를 제공한다. 명령 검색에서도 색상 항목을 찾는다. 사용자 지정은 불투명 sRGB로 저장된다.

`Project.circleColors`는 optional 주소별 override다. 같은 원본을 재사용해도 section use 주소별로 지정되며, 구형 프로젝트의 필드 누락은 기본색으로 해석한다. 기본색 복원은 override를 제거한다. 변경은 Undo에 들어가고 음악 데이터는 변경하지 않는다. 색상 전용 Undo/Redo는 최신 음악·화면·포트 배치와 musicRevision을 유지한다.

사용자 지정 패널이 열려 있어도 프로젝트가 바뀌거나 대상이 삭제되면 대상을 해제한다. 삭제 후 Undo로 서클이 돌아와도 이전 패널은 다시 연결되지 않는다.

## 검증 상태

- 색상/기존 history 테스트 14개 통과.
- 실제 우클릭·C 메뉴·명령 검색·사용자 지정·Undo·저장/재열기·기본값 복원 및 패널 초기화 검증 통과. [QA](../qa/circle-color-review.md).
- 사용자 앱 교체는 물리 오디오 출고 조건 검증 뒤 진행한다.
