# 0.13 캔버스 조작과 영상

작업은 기존 단일 캔버스에서 이뤄진다. 명령 검색과 도움말은 필요할 때만 겹쳐 보이며, 상시 좌우 패널을 추가하지 않는다.

## 만들기와 탐색

빈 공간을 우클릭하면 현재 작업 계층에 맞는 생성 메뉴가 열린다. 앨범은 곡, 곡·악장은 섹션/악장, 섹션은 MIDI/오디오/이펙터, 앨범 사운드는 버스/전역 이펙터를 제공한다. 자유 배치는 클릭 좌표를 부모 서클의 로컬 좌표로 변환하고 grid snap을 적용한다. 궤도 모드는 음악의 시간·재생 순서로 위치를 결정한다.

서클을 우클릭하거나 `C`를 누르면 확대, 설정, 연결, 연결 해제, 삭제가 나온다. 오디오 소스에는 호환 compressor로 보내는 사이드체인 메뉴가 있다. `A`는 선택 계층의 생성 메뉴다.

`⇧⌘P`는 명령과 서클 이름을 검색한다. 여러 검색어는 모두 포함해야 하며 영문 대소문자를 구분하지 않는다. 방향키로 선택, Return으로 실행, Esc로 닫는다. 한글 조합 중 Return/방향키는 IME에 전달한다. 검색 행의 identity는 명령 ID이며 화면 제목·클릭·Return이 같은 명령을 가리킨다.

| 키 | 기능 |
|---|---|
| Tab / ⇧Tab, 방향키 | 같은 계층의 서클 순회 |
| ⇧방향키 | 같은 부모 안에서 선택 추가/해제 |
| Return / Esc | 하위 서클·편집기로 진입 / 상위로 이동 |
| R | 선택 서클 이름·음악 설정, 이름 입력 포커스 |
| ⌥⌘0 | 어느 편집기에서든 캔버스로 포커스 복귀 |
| + / −, F | 확대·축소, 전체 앨범 |
| ⌥방향키 | 화면 이동 |
| ⇧⌥방향키 | 자유 배치에서 선택 서클을 grid 간격만큼 이동 |
| ⌘G / ⌘D / ⌘K | 그룹 / 섹션 재사용 / 섹션 추가 |
| Space / Delete | 재생·정지 / 선택 삭제 |
| ⌘Z / ⇧⌘Z | 실행 취소 / 다시 실행 |
| ⌘N / ⌘O / ⌘S / ⇧⌘S | 새 앨범 / 열기 / 저장 / 다른 이름으로 저장 |
| ⌘I / ⌘E | 오디오 가져오기 / WAV 내보내기 |
| ⌃` / ⌘/ | 콘솔 / 단축키 도움말 |
| ⌘W / ⌘Q | 최소화 / 종료 |

글로벌 설정, 악기·효과, 리듬 패턴, 연결·전환, MIDI 생성/저장, 바운스, 녹음, 그리드, 팔로우는 명령 검색과 설정의 Tab 이동으로 접근한다. 외부 Audio Unit의 자체 UI는 해당 플러그인의 키보드 접근성을 따른다. 8방향 포트 위치 조작은 별도 후속 설계다.

## 같은 캔버스에서 정밀 편집

MIDI 서클에서 Return으로 편집기에 진입한다. Tab으로 노트를 순회하고 Return으로 현재 박에 노트를 만든다. ←/→는 격자 단위 시간, ↑/↓는 반음 이동, ⇧←/→는 길이, ⇧↑/↓는 옥타브, ⌥↑/↓는 velocity ±5다. 음높이 0–127, velocity 1–127, 섹션 시간 경계를 지킨다. 원형·자유 배치 편집기가 같은 키맵을 사용한다. 이름·숫자 입력 중에는 문자 핫키를 실행하지 않는다.

오디오 편집기의 ←/→는 원본 시작을 0.01초, ⌥←/→는 원본 끝을 0.01초 조절한다. Shift와 함께 쓰면 0.1초다. 시작 박, gain, tempo 추종 등은 설정 입력으로 조정한다. MIDI/오디오 편집기의 Esc는 캔버스를 다시 선택하고 상위 서클로 돌아간다.

## MP4 녹화

상단 녹화 버튼 또는 `⇧⌘R`로 새 MP4 파일을 지정한다. 앨범 오디오를 준비하고 처음부터 재생하면서 캔버스 프레임과 같은 PCM을 H.264/AAC로 저장한다. 녹화 버튼을 다시 누르면 영상을 마치고 음악은 계속 재생한다. Space/정지는 음악과 녹화를 함께 마친다. 준비 중 재입력은 준비를 취소한다.

- 영상: 캔버스 종횡비, 최대 1920×1080, 30Hz 캡처 시도, 실제 재생 sample time을 presentation timestamp로 사용. 입력·인코더 부하에 따라 가변 프레임 간격이 될 수 있다.
- 오디오: 준비된 48kHz stereo PCM, AAC 256kbps. 시스템 마이크나 다른 앱의 소리를 녹음하지 않는다.
- 범위: 서클·연결선 캔버스. 헤더·콘솔·파일 선택창은 포함하지 않고, 녹화 중 정밀 편집기를 숨긴다.
- 녹화 중 최소화에도 프레임 갱신을 유지하는 경로를 구현했다. 일반 최소화에서는 기존처럼 시각화 작업을 멈춘다.
- 프로젝트 음악 revision이 바뀌면 녹화를 마친다. 취소된 준비의 늦은 callback은 새 녹화를 시작하지 못한다.
- 기존 파일을 덮어쓰지 않는다. 숨긴 staging 파일을 먼저 작성하고 인코딩 완료 후 최종 이름으로 이동한다. 종료 요청은 진행 중인 파일 마무리를 기다린다.
- 완료한 파일은 명령 검색의 `저장한 영상 Finder에서 보기`로 찾는다.

실제 화면 녹화의 검증 상태는 [0.13 QA](../qa/0.13-review.md)를 따른다. 코덱 단위 테스트와 실제 재생 장치·최소화·녹화 동작을 구분한다.

## 엔진과 품질

새 악기 트랙은 내장 키 음색으로 시작한다. 신스 엔진 2는 mono 베이스, velocity에 따라 배음이 바뀌는 키, PolyBLEP saw, TPT low-pass, 공명·스테레오 폭·옥타브 단위 필터 엔벌로프를 사용한다. 64 voices와 고정 event queue를 사용하며 렌더 callback에서 할당·mutex를 사용하지 않는다. 새 reverb는 pre-delay, 저역 정리, 감쇠되는 comb와 all-pass 확산을 사용한다.

기존 patch에 engineVersion이 없으면 엔진 1, 기존 reverb에 renderVersion이 없으면 이전 알고리즘으로 읽는다. 신스의 `새 신스 엔진으로 전환`은 명시적 편집이며 Undo할 수 있다. 새 음색은 0.13 이상에서 재생해야 같은 결과를 얻는다.

오프라인 AU는 노드를 연결하기 전에 offline mode를 활성화한다. 실시간 기본 출력 연결이 10초를 넘으면 오류를 보고하고 편집 UI는 응답을 유지한다. 진행 중인 시스템 호출 자체를 강제로 종료하는 기능은 아니다.
