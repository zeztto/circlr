# 찾을 수 있는 편집 조작 — build75

planning-gate-v1: development-lead. 기준dc55720, integration worktree. 실제 슬롯 제한에 따라 UX/native/review/QA 순차 수행.

키보드 도움말에 검색과 전체/공통/캔버스/MIDI/오디오/오토메이션 필터를 추가한다. 처음 열 때 현재 편집 종류를 선택하고 모든 조작은 전체 필터에서 접근할 수 있다. 찾는 결과가 없으면 검색 범위를 전체로 넓히는 동작을 제공한다. 최근 피아노 롤 F/오디오 Tab·Shift+Tab/수치 Return·Esc를 문서와 일치시킨다. 검색 결과에 단축키와 실제 설명을 함께 유지한다. 명령 팔레트도 shortcut 문자열을 검색한다. 실제 명령의 실행 계약은 변경하지 않는다.

검증: 작은 창 현재 오디오 범위, 텍스트/단축키 검색, 결과 없음→전체 범위, 필터별 내용, 피아노 롤 F 안내, 명령 ⌘S 검색 및 실행. 보기 탐색 자체는 음악/Undo 변경 없음. 사용자 앱/원본 음악 보존.

구현·검증 완료: 제목/단축키 정확 일치 → 제목 접두 → 제목 내 모든 단어 → 설명 포함 순서이며 같은 등급의 기존 순서를 보존한다. 오디오9/MIDI13/오토메이션3/전체54 도움말, 검색/키보드 스크롤과 저장 명령을 검증했다. 잘못된 초기 경쟁 조건 진단 및 복원 범위는 [QA](../qa/shortcut-search-review.md)에 기록했다. 물리 출력과 사용자 앱 교체는 별도다.
