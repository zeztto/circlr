# circlr 1.3.0 · 작품 보존과 미디어 복구

상태 / Status: **build259 검증 후보 · 미출고 / Unreleased candidate · 실제 IME 사용자 검수와 최종 출고 판단 대기**

## 한국어

1.3은 저장 실패 때 기존 작품을 보존하고, 누락된 미디어를 다시 연결하는 작업을 개선합니다.

- **원자적 저장:** 기존 곡을 완전한 새 프로젝트와 원자적으로 교체합니다. 저장 중 실패나 다른 작업의 파일 변경을 감지하면 기존 파일을 보호하고 오류를 알립니다.
- **곡 미디어와 복구:** 파일 메뉴 또는 ⇧⌘P 명령 검색에서 미디어를 검사하고 **원본 찾기…**로 재연결합니다. 이름이 같아도 checksum이 다르면 원본으로 연결하지 않습니다. checksum 없는 구형 자료는 명시적 대체 동의를 받습니다. 변경은 해당 asset의 모든 참조에 적용되며 Undo할 수 있습니다.
- **미디어 포함 사본:** 새 목적지에 필요한 오디오를 포함한 프로젝트 사본을 저장합니다. 현재 열린 원본과 미저장 상태는 유지합니다.
- **진단과 복구 안내:** 이름·경로·오디오·계정 정보·대화 로그를 제외한 진단 JSON을 사용자가 직접 저장합니다. 읽을 수 없는 복구 파일은 보존 위치와 함께 경고하며 Finder에서 확인할 수 있습니다.
- **입력 경계:** 미디어 화면의 Tab·Return·Space·Esc 동작과 텍스트 입력/음악 명령 분리를 보완했습니다. 실제 한글 조합 검수는 아래 제한과 구분합니다.

**확인한 범위:** 저장 게시 전후의 격리 process 종료, 미디어·manifest 쓰기 중 공간 부족, 복구 소유권과 외부 파일 변경 보호를 자동/process 검사했습니다. 실제 앱에서는 미디어 사본·재연결·legacy 대체 동의, 저장/cold reopen, 진단 저장, 복구 decode/migration 실패의 경고·원본 보존, 700pt 핵심 키보드 조작을 확인했습니다. 저장 오류 후 dirty·Undo 유지와 정상 저장 재시도도 확인했습니다. 각 검사의 후보 build와 PARTIAL/OPEN은 [QA 기록](../../qa/1.3-plan.md)을 따릅니다.

**남은 제한:** 실제 Korean IME 조합은 사용자 검수 대기입니다. 진행 중 작업은 실제 helper와 종료 delegate 검사로, native 종료는 작업이 없는 상태에서 각각 확인했습니다. HFS+에서 기존 곡 덮어쓰기는 ENOTSUP으로 거절될 수 있습니다. 기존 곡을 삭제하지 말고 **다른 이름으로 저장…** 또는 새 위치의 사본 저장을 사용하세요. 실제 청취·장치 호환성·장시간 영상 70ms 실패와 계정 실서비스 검증 보류 등 [1.2의 기존 제한](1.2.0-notes.md)은 해결됐다고 주장하지 않습니다. 계정 대화 UI는 기본 비활성화하며 로컬 MCP·명령 콘솔은 유지합니다.

**설치:** Apple Silicon용 앱은 ad-hoc 서명이며 notarization되지 않았습니다. macOS가 실행을 막으면 출처와 checksum을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 사용합니다. [macOS 설치 안내](../install-macos.md) · [미디어 복구 사용·검수 안내](../1.3-media-recovery-guide.md).

## English

Version 1.3 improves project preservation and missing-media recovery. See the status line above for release availability.

- **Atomic saving:** Replace an existing project with a complete new package. Failed publication or conflicting file changes preserve the existing project and report an error.
- **Media recovery:** Open **곡 미디어와 복구…** from the File menu or Shift–Command–P. Relinking validates content rather than filenames. Legacy assets without checksums require explicit replacement consent. Changes affect all references to the asset and support Undo.
- **Portable copies:** Collect audio into a new project copy without switching the open document or clearing its unsaved changes.
- **Diagnostics and recovery notices:** Explicitly export a local JSON report excluding names, paths, audio, credentials and conversation logs. Unreadable recovery files are preserved with a visible location and Finder action.
- **Input handling:** Improve keyboard activation and the boundary between text input and music commands. This does not establish full real-world IME validation.

**Verified scope:** Isolated process and automated checks cover publication interruption, media/manifest disk-full failures, recovery ownership and foreign-file protection. Native checks cover portable copies, relinking and legacy consent, save/cold reopen, diagnostic export, decode/migration recovery notices, core 700pt keyboard actions, and dirty/Undo preservation followed by successful save retry. Consult the [QA record](../../qa/1.3-plan.md) for build-specific and partial results.

**Limits:** Real Korean IME composition awaits user validation. In-flight termination was tested through the actual delegate and real helper; native process exit was checked separately while idle. Existing-project overwrite may be rejected on HFS+ with ENOTSUP; preserve the original and use Save As or a new portable-copy destination. Existing audio/device, long-video and paused account-service limitations from [1.2](1.2.0-notes.md) remain. Account chat stays hidden by default; local MCP and command-console access remain available.

**Installation:** The Apple Silicon app is ad-hoc signed, not notarized. If macOS blocks it, verify the source/checksum and use System Settings → Privacy & Security → Open Anyway. [Installation guide](../install-macos.md#english).
