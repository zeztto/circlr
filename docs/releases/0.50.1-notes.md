# circlr 0.50.1 · build169

## 한국어

- 앨범·곡·섹션과 MIDI·오디오·악기·이펙트·출력의 크기를 구분했습니다.
- 기본 배치를 중심에서 펼치고, 연결된 신호 노드가 바깥으로 이어지도록 간격을 늘렸습니다.
- **자동 정렬**에서 **중심에서 방사형**, **가로 신호 흐름**, **세로 신호 흐름**을 선택합니다. 여러 서클을 선택하면 선택 범위에, 그 외에는 현재 컨테이너 안에 적용합니다. 음악 시간과 연결을 유지하고 한 번의 Undo로 복원합니다.
- README의 가로·세로 화면을 이번 버전의 실제 스크린샷으로 갱신합니다.

macOS14 이상 Apple Silicon용. ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 첫 실행이 차단되면 [설치 안내](../install-macos.md#한국어)를 확인하세요. [QA 결과](0.50.1-qa.md).

## English

- Different circle sizes distinguish albums, songs, sections, MIDI, audio, instruments, effects and outputs.
- Default placement expands from the center, with more space between circles and signal chains extending outward.
- **Auto layout** offers radial, horizontal and vertical signal-flow layouts. Apply it to a multiple selection or the current container. Musical timing and connections remain intact; one Undo restores the previous placement.
- README screenshots are refreshed from this version's actual landscape and portrait app windows.

Requires macOS14+ on Apple Silicon. Ad-hoc signed, not Apple-notarized. If first launch is blocked, see [installation instructions](../install-macos.md#english). [QA record](0.50.1-qa.md).
