# circlr 0.40.0 · build162

## 한국어

써클을 더 읽기 쉽게 만들고, 곡 구성과 반복 청취를 한 캔버스에서 이어갑니다.

- **가시성:** 궤도·연결·선택·IN/OUT 대비, 라벨 크기·측정 영역, MIDI 음높이·오디오 시간 표시와 작업 상태를 개선했습니다.
- **감상과 팔로우:** ⇧⌘V로 텍스트와 편집 UI를 숨깁니다. 곡·섹션·고정 서클을 팔로우하고 구도 및 줌 전환 강도를 고릅니다. Esc로 돌아오며 입력 초안을 보호합니다.
- **루프:** 곡 전체 또는 섹션을 연속 PCM으로 반복합니다. 실행 중 명시적으로 바꾼 범위는 다음 안전한 출력 경계에 적용하고, 루프 해제는 잔향을 마친 뒤 정지합니다. GUI와 MCP에 예약 상태를 표시합니다.
- **영상:** 최대1920×1080으로 직접 캡처하며 인코딩은 직렬 background queue에서 처리합니다. 루프·범위 변경·종료 잔향을 영상의 오디오에도 반영합니다.
- **시작 화면:** 새 곡의 템포·박자·스케일, 전자음악/피아노/밴드 템플릿, 기존 파일과 동봉 데모를 선택합니다. 데모 복사는 백그라운드에서 취소할 수 있고 원본을 보존합니다.
- **데모4곡:** 최신 f0r h3r v5와 Bach Invention No.8/No.7, Beethoven Für Elise를 포함합니다. 클래식 MIDI는 출처를 기록하고 섹션·악기·역할 컬러를 구성했습니다.
- **에이전트:** workspace_view, live playback_loop와 진행 상태를 추가하고 동봉 Codex kit를 갱신했습니다.

macOS14 이상 Apple Silicon용입니다. 앱은 ad-hoc 서명이며 Apple 공증은 없습니다. 이전 앱과 중요한 프로젝트의 사본을 보존하세요. 코드·문서·아이콘은 MIT, 곡/편곡은 별도 데모 조건이며 원본 CC0/Public Domain 권리는 유지됩니다.

**검증 범위:** 변경 관련 자동 검사와 offline PCM/MP4 재디코드, 소스 검토를 수행했습니다. 실제 GUI·청취·장시간 FPS·한글 IME는 사용자의 명시적 요청으로 USER_WAIVED입니다. 실제 무중단 청취나 FPS를 측정한 릴리스로 해석하지 마세요. [검증 기록](https://github.com/zeztto/circlr/blob/v0.40.0/docs/releases/0.40.0-final-qa.md).

## English

This release improves circle readability and connects song structure, repeat listening and presentation on one canvas.

- Stronger orbit, connection, selection and IN/OUT contrast; larger measured labels, MIDI pitch/audio time readouts and visible work status.
- Text-free viewing with Shift–Command–V, Escape to return, protected input drafts, and song/section/pinned-circle follow with framing and transition controls.
- Continuous PCM song/section loops. Explicit live changes apply at the next safe unsubmitted output boundary; disabling a loop drains its finite tail. GUI and MCP distinguish pending from applied changes.
- Direct capture up to1920×1080 and bounded background encoding. Recorded audio follows the same loop, replacement and exit-tail timeline.
- A startup workspace with tempo/meter/scale, electronic/piano/band templates and cancellable background demo copying.
- Four bundled demos: f0r h3r v5, Bach Inventions No.8 and No.7, and Beethoven’s Für Elise, arranged into sections, instrument roles and colors with source notices.
- workspace_view/live playback_loop tools and an updated bundled Codex kit.

Requires macOS14+ on Apple Silicon. The app is ad-hoc signed, not Apple-notarized. Preserve the previous app and copies of important projects. Software, documentation and icons are MIT; music uses separate demo terms, with original CC0/Public Domain rights preserved.

**Verification:** targeted automated tests, offline PCM/MP4 decoding and source reviews were completed. Native GUI/listening, sustained FPS and Korean IME testing were explicitly USER_WAIVED. This release does not claim measured native gaplessness or frame rate. See the linked verification record above.
