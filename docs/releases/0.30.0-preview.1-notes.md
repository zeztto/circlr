# circlr 0.30.0-preview.1

## 한국어

현재 개발 소스를 `main`에 통합한 **평가용 프리릴리스**입니다. 앱 내부 버전은 **0.30.0, build158**입니다. 0.30.0 마일스톤의 전체 QA 완료판이 아닙니다.

### 주요 변경

- 앱 상단 로고 아래에 실행 중인 **버전·build** 표시. 패키지의 Info.plist와 같은 값을 사용합니다.
- 하나의 캔버스에서 송폼·섹션·MIDI·오디오·악기·이펙트를 연결하고 편집하는 현재 기능을 통합했습니다.
- MIDI 파일 비동기 읽기·취소 처리, 페달 포커스·스텝 Tab 이동, 높은 콘솔에서 가려지던 페달 필드 접근을 개선했습니다.
- 한국어·영어 README, 실제 편집 화면, 기여·에이전트 안내와 릴리스 절차를 정리했습니다.

### 설치

- 패키지: `circlr-0.30.0-preview.1-macos-arm64.zip`.
- Apple Silicon Mac 전용, 앱 최소 요구 macOS 14. 모든 macOS 14 이상 환경에서 검증했다는 뜻은 아닙니다. Intel용 바이너리는 포함하지 않습니다.
- ZIP을 풀어 써클러 앱을 실행합니다. 기존 앱과 프로젝트를 먼저 별도 보관하세요. 이 배포 작업은 사용자 설치 앱을 자동 교체하지 않습니다.
- ad-hoc 서명이며 Apple notarization은 없습니다. macOS의 일반 앱 실행 보안 정책이 적용됩니다.
- ZIP과 `SHA256SUMS`를 같은 폴더에 받아 `shasum -a 256 -c SHA256SUMS`로 확인합니다.
- 프로젝트·Splice 샘플·개인 설정·인증정보는 포함하지 않습니다. 저장소는 비공개이며 접근 권한이 필요합니다.

### 검증과 남은 범위

- 앞선 build157까지 Swift Core/선별 Audio 678개·Python MCP 29개 통과. MIDI 가져오기·Undo·CPU 바운스·원본 복원·GUI/MCP 데이터 일치·저장 재열기 등을 부분 검증했습니다.
- build158은 버전 표시 변경에 대해 앱·5 helper·키트를 함께 빌드하고, 표시·패키지·서명·ZIP 복원과 배포 후 다운로드 체크섬을 확인합니다. 기존 전체 테스트를 새로 실행했다고 주장하지 않습니다.
- **실제 오디오 출력·한글 IME·장치/플러그인 호환성·일부 통합 QA는 미완료입니다.** 녹음·영상·재생 표시가 있다는 이유만으로 해당 장치에서 검증된 기능으로 간주하지 마세요.
- 현재 오디오는 준비한 PCM을 재생하는 구조입니다. 범용 실시간 DAW 엔진의 완성판이 아닙니다.
- 이번 버전 표시 변경은 저장 schema를 바꾸지 않습니다. 개발 중인 프로젝트는 새 사본으로 저장하고, 문제가 생기면 이전 앱과 그 앱에서 저장한 프로젝트 백업을 함께 복원하세요.

## English

An **evaluation prerelease** of the current development work integrated into `main`. The app reports **0.30.0, build158**. This does not complete the 0.30.0 milestone or its full QA checklist.

### Changes

- The header now displays the running app's **version and build**, read from its Info.plist.
- Integrates the current single-canvas song-form, section, MIDI, audio, instrument and effect editing workflow.
- Improves asynchronous MIDI file reading/cancellation, pedal focus, step-editor Tab navigation and pedal controls hidden behind a tall console.
- Adds English/Korean README files, real editing screenshots, contributor/agent guidance and a release procedure.

### Installation

- Asset: `circlr-0.30.0-preview.1-macos-arm64.zip`.
- Apple Silicon only; the app declares macOS 14 as its minimum. This is not a claim of testing every supported OS. No Intel binary is included.
- Extract and open the app. Keep your existing app and projects separately backed up. Publishing this release does not replace the installed app automatically.
- Ad-hoc signed, **not notarized**. Normal macOS application security policies apply.
- Download the ZIP and `SHA256SUMS` into one directory and run `shasum -a 256 -c SHA256SUMS`.
- No music projects, Splice samples, personal settings or credentials are included. Repository access is required while it remains private.

### Verification and limitations

- Prior work through build157 passed 678 Swift Core/selected Audio tests and 29 Python MCP tests, with partial native checks of MIDI import, Undo, CPU bounce/restoration, GUI/MCP data equivalence and save/reopen.
- build158 rebuilds the app, all five helpers and the agent kit for the version-label change. Its label, packaging, signature, ZIP extraction and release download checksums are checked separately; the full test suite has not been rerun.
- **Physical audio output, Korean IME input, device/plug-in compatibility and parts of integration QA remain unverified.** Visible recording, video or playback controls do not certify operation with your hardware.
- Playback currently uses prepared PCM. This is not a complete general-purpose real-time DAW engine.
- The version-label change does not alter the project schema. Save development projects as separate copies; recover using the previous app together with a project backup made by that version.
