## 독립 검토와 수정

- 시작 화면 복구 우선순위, 감상 모드 reset callback, 시작 화면 뒤 편집 단축키 차단.
- 새 프로젝트 migration 성공 전에 현재 demo 사본을 정리하던 순서를 변경.
- 긴 loop의 ACK를 실제 경계 직전까지 미루던 결함 수정: 다음 미예약 경계를 즉시 예약/응답.
- 오래된 변경 Task 취소는 해당 output session에만 적용.
- 자연 종료의 정확한 sample frame을 별도 보존하고 MP4 종료 길이에 반영.

`r40_modes_review`와 `r40_integrated_review`의 지적을 수정하고 관련 검사를 실행했다. demo 복사는 generation·전체project·경로를 다시 확인하므로 취소나 다른 작업 뒤 늦은 결과가 문서를 덮지 않는다. managed reader는 사본을 영구 보존 표시하며, 이전/untracked 사본을 탐색·삭제하지 않는다. 외부 raw reader/구버전 앱 참조의 전역 탐지를 주장하지 않는다.

## 사용 범위

- 루프 첫 주기부터 유한 tail을 합산한 circular steady-state PCM을 사용한다. 범위 교체 시 이전 범위 tail은 끝내고 새 cycle로 전환한다. 해제 시 기존 finite exit tail 뒤 정지한다.
- 예약된 output buffer는 다시 쓰지 않는다. 변경은 다음 아직 제출되지 않은 안전한 경계에서 적용하며 GUI/MCP는 pending과 실제 적용을 구분한다.
- 일회 재생 중 loop 설정은 다음 Play에 적용한다. 오디오/MIDI 녹음 중 loop 변경은 거부한다. 영상 녹화는 같은 PCM 경계를 사용한다.
- 실제 장치의 무중단 청취·GUI 가독성·장시간 FPS/AV 동기·IME는 이번 버전에서 실측하지 않았다. 0.30의 사용자 청취 확인을0.40 결과로 재사용하지 않는다.
- 배포는 macOS14+ Apple Silicon, ad-hoc 서명이며 공증/Intel 검증을 포함하지 않는다. 현재 사용자 실행 앱을 교체하지 않는다.
