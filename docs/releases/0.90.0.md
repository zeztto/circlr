# 0.90.0 — 핵심 음악 제작과 비주얼라이저 신뢰성

상태: PLANNED · 기준: [0.80.0 개발 후보](0.80.0.md) · 최신 정식판: `v0.70.0`. 0.80이 아직 출고되지 않았으므로 이 문서는 완료나 출고 승인이 아니다. 버전 숫자는 작업 순서이고, 실제 재생·제작·저장·영상 결과가 완료 기준이다.

## 범위 결정

사용자는 0.90까지 개발하되 핵심 기능의 실제 동작과 UI 개선을 버전 숫자보다 우선한다. 먼저 0.80에서 짧은 실사용 제작 경로를 안정화하고, 0.90에서 같은 경로의 반복·장시간·고밀도·오류 복구를 보증한다. 기존 아티스트 프로필·작품 catalog·자산 백업 목표는 [아티스트 설계](../21-artist-universe.md)에 보존하고 음악 제작 gate 통과 뒤 착수한다. Codex 계정 대화는 공식 production 지원 경로를 확인할 때까지 [G0](0.80.0.md) 밖에 두며 기존 typed MCP와 작업 로그는 유지한다.

## 작업과 인수 증거

| ID | 사용자 결과 | 최소 인수 증거 |
|---|---|---|
| R90-01 | 앱을 열어 재생·정지·재시도를 반복해도 출력이 멈추지 않는다 | 최종 패키지의 동일 빌드를 cold start하고 내장 출력·Scarlett 각각 반복 Play/Stop/자연 종료·장치 변경·실패 후 재시도. helper trace의 시작/정리와 실제 청취를 별도 기록. 다른 앱/시스템 장치 설정은 QA 범위 밖에서 변경하지 않음 |
| R90-02 | 곡과 섹션을 루프로 끊김 없이 듣고 재생 위치를 믿을 수 있다 | 100회 offline 경계의 sample 수·위상·tail·누적 drift 검사에 더해 실제 장치의 곡/섹션 경계 청취. 전환·루프 해제·Stop 뒤 잔음·재시작과 카메라 팔로우의 재생 위치 대조 |
| R90-03 | 비주얼라이저를 1080p/30fps 영상으로 안전하게 저장한다 | 고밀도·섹션 전환·루프가 있는 같은 후보에서 1920×1080 10분 MP4. decoded frame PTS 간격/중복·누락, 시작/중간/끝 AV offset 1프레임 이내, 별도 플레이어 시청·청취. 취소·디스크 실패·최소화/복원과 임시 파일 정리 |
| R90-04 | 한 곡을 편집·보존·되돌리고 실제 결과물로 출력한다 | 격리 QA 곡에서 섹션 이동, MIDI/step, 오디오 take trim/split/fade, 효과/automation, Undo/Redo → 저장·앱 종료·재열기 → 바운스/WAV/stems. manifest·media hash와 원본 데모 불변, 출력 길이·nonzero PCM·별도 청취를 확인 |
| R90-05 | 넓고 좁은 가로·세로 화면에서 궤도 작업과 감상이 편하다 | 700/900/1280pt, 가로·세로, 3 zoom × 정지/재생/감상/녹화에서 같은 곡·카메라로 화면 비교. 선택 cable·현재 섹션·8방향 IN/OUT의 시각/키보드/AX, hit/Undo 불변. 실제 compositor FPS를 콜백 Hz와 구분해 측정 |
| R90-06 | 설치한 앱이 검증한 앱과 같다 | 전체 회귀·독립 코드/QA 검토, 한영 README·스크린샷·CHANGELOG·노트, 앱/5 helpers/데모/kit 서명·버전 일치, ZIP 재압축/재다운로드 SHA 검증. 미해결 필수 gate가 있으면 tag/Release 보류 |

각 항목은 자동 테스트, 고립된 native QA 앱, 실제 장치/파일, 배포물의 증거를 구분한다. mock·offline PCM·타이머 callback 통과는 물리 청취나 실제 표시 FPS의 대용이 아니다. 장치 의존 결함이 재현되지 않을 때는 무조건 timeout 연장이나 자동 재시도를 제품 정책으로 넣지 않고 stage trace·재현 조건을 먼저 남긴다. 0.80.x는 0.80.0 정식 출고 뒤 발견한 좁은 결함만 수정하고 동일한 관련 gate를 다시 통과한 경우에 사용한다.

## 다음 작업 경계

0.80에서 먼저 [재생 출력 준비](0.80.0.md), 녹화 준비 취소/짧은 MP4, 한 곡 저장·바운스, 궤도 가독성·반응형 UI를 검증한다. 이 기준이 열려 있는 동안 0.90의 장시간 수치나 아티스트 catalog 완료를 주장하지 않는다. 사용자 앱 교체, tag, 공개 Release는 별도 출고 판단 뒤에 한다.
