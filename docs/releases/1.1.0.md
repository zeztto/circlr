1. 공식 지원·약관 및 실제 계정 로그인/로그아웃·refresh·오프라인 복구 확인.

## 첫 검토에서 발견한 필수 수정

- R110-01: 신규 host ID를 공식 `urn:uuid:` 형식으로 발급한다. 등록된 identity의 host를 임의 회전하지 않으며 무효 refresh credential은 재로그인으로 안내한다.
- R110-02: 서비스 eligibility·플랜 한도·일시 장애를 허용된 오류 코드로만 구분하고 원문 응답/토큰은 표시하지 않는다.
- R110-03: 64개 초과 MIDI 노트를 부분 조회하고 전체 교체해 미조회 노트를 잃는 경로를 차단한다. 앱이 수락한 바운스/저장 job의 완료를 확인하기 전에는 성공을 표시하지 않는다.

1.1 배포 형태는 무료 오픈소스 macOS 로컬 앱이다. 유료/원격 호스팅 서비스 승인을 주장하지 않는다. 계정은 동시에 하나만 연결하며 다중 프로필 저장/선택을 약속하지 않는다. 실제 ChatGPT 플랜 사용 권한을 받지 못하면 모델 호출을 차단하고 로그인/동의 복구를 안내한다. API key나 Codex 글로벌 자격 증명을 읽는 우회 경로를 만들지 않는다.

공식 근거: [OSS/local 개요](https://developers.openai.com/siwc/token-sharing-open-source), [로그인](https://developers.openai.com/siwc/token-sharing-open-source/sign-in), [모델 호출](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference), [오류 복구](https://developers.openai.com/siwc/token-sharing-open-source/errors-and-recovery). 문서 적합성은 실제 계정 eligibility 성공의 증거가 아니다.

## 2026-09-30 실서비스 검증 보류와 독립 UI 작업

사용자가 서비스 문제를 의심하며 다른 부분을 먼저 개발하도록 지시해 추가 모델 호출을 보류한다. 실제 OAuth 동의·Keychain 재연결·모델 목록 조회는 성공했다. 요청은 `response.completed`의 빈 `output`으로 끝났으며 서비스 자체 장애로 단정하지 않는다. 공식 요청 계약 대조에서는 결정적인 위반을 발견하지 못했다. [build250 증거](../../qa/1.1-account-chat.md).

다음 독립 작업은 콘솔 계정/모델 행 압축, 긴 오류의 제한된 표시 영역, 창 크기 변경 후 모드 유지, 초안·키보드·700pt UI 검증이다. 모델 실작업 합격과 정식1.1 출고는 보류하며 현재 정식판은1.0.0이다.
