## 실제 오디오 관측

`final160/audio-start.json`은 build160에서 `actualOutputDeviceName=Scarlett 6i6 USB`, `didStart=true`, transport `playing`을 기록합니다. `audio-natural-end.json`은 자연 종료, `audio-stop.json`은 두 번째 시도 후 idle을 기록합니다. 리드의 native 실행 기록에 따라 재재생과 정지를 확인했습니다. 사용자는 해당 청취에 대해 **“정상적으로 들림”**으로 확인했습니다. 실제 한글 IME 확인은 별도로 대기 중입니다.

`final160/audio-devices.json`의 시스템 장치 정보는 Scarlett 6i6 USB가 기본 출력이며 nominal rate 44,100 Hz임을 기록합니다. `final160/device-buffer.txt`의 CoreAudio 조회는 buffer 512 frames, status 0을 기록합니다. 기준 오디오 파일과 render 입력은 48,000 Hz입니다. 장치 rate와 파일 rate를 구분합니다. 실패 복구·helper 회수·최종 artifact hash는 Q06 마감 시 추가합니다.

build160 master export 측정은 14초(12초 본문+2초 tail), 48 kHz stereo 24-bit, 672,000 frames, peak 약 0.12679, RMS 약 0.02043이며 end window는 무음입니다. `final160/master-job.json`과 `final160/master.json`에 보존합니다. 이는 export 결과이며 bounce 원본 복구나 이 WAV의 별도 청취를 대신하지 않습니다.
