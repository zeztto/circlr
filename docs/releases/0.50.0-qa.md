## 제한과 후속 검사

이번 변경은 궤도·반응형 UI에 한정한다. 한글 IME, 실제 장치 녹음, 장시간 녹화 FPS, 별도 청취, 모든 port/시간 handle 조합의 수동 드래그는 이번 native 시나리오에서 재수행하지 않았다. 시간/배치 분리와 migration은 Core 회귀 및 코드 검토 근거이며 전체 native 조합 PASS로 확대하지 않는다. 0.40 QA 유예를 이번 버전의 PASS 근거로 사용하지 않았다. Gatekeeper 문서는 공식 지침·서명 상태를 검증했으며 다운로드 격리 경고를 직접 재현한 결과는 아니다.
