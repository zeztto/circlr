## 발견·수정과 근거 제외

- build154 Step Tab이 console로 이동: NumberFieldFocus에 연결하여 build155에서 Tab·Shift-Tab·페이지2 입력을 확인했다.
- 비동기 MIDI 읽기 동안 library access가 먼저 해제될 수 있다는 P1: worker 종료까지 LibraryAccess를 보유하도록 수정, 독립 재검토 PASS. 네트워크/OS 파일 읽기를 강제 중단하는 구현은 아니며 취소 후 늦은 적용을 막는다.
- build155 높은 콘솔에서 페달 raw 필드가 가려짐: `155-22-invalid-confirmed.png/.txt`. 입력 오류 차단은 정상이나 가시성 조건은 FAIL. build156에 세로 스크롤을 추가했으나 Tab 자동 노출은 실패했다. 수동 휠 이동으로 수치·오류에 접근 가능함을 `156-02-scrolled.png`에서 확인했다. build157은 중첩 가로 스크롤을 기존 줄바꿈 Layout으로 교체한다. 공통 NumberFieldFocus 변경은 없다. build157의 `157-01-invalid.png/.txt`에서 Tab Tab으로 raw 필드가 자동 노출되고 128 오류 badge가 표시됨을 확인했다. `157-02-mode-block.txt`는 모드 전환 차단, `157-03-recovered.png/.txt`는 Escape로0 복구·콘솔40에서 넓어진 그래프다.
- `155-01-reopen.txt`는 잘못 선택된 이전 QA 앱 기록이므로 제외한다. 해당 소유 QA 프로세스만 종료하고 CUA를 reset한 후 build155를 다시 선택했다.
- `155-21-invalid-draft.txt`에서는 pointer 클릭이 필드에 진입하지 않아 실제 invalid draft가 입력되지 않았다. Tab으로 진입·128 표시를 확인한 `155-22-invalid-confirmed`를 근거로 쓴다.
- no-I/O QA console에 SoundBank helper exit78 준비 실패가 기록됐다. stub 차단 상태이므로 실제 장치 실패 원인이나 성공으로 해석하지 않는다. 출력·audition attempts는 계속0이다.
