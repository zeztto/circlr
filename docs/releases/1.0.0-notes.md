# circlr 1.0.0 · build245

## 한국어

MIDI 녹음의 노트·sustain(CC64)·pitch bend를 채널별 take에 보존합니다. 녹음 전 편집본으로 돌아가거나 전체 녹음을 한 번에 Undo/Redo할 수 있습니다. 표현만 덧녹음하면 기존 노트와 기록하지 않은 표현을 유지합니다. 기존 궤도형 송폼 편집, 오디오·MIDI·step 편집, FX·automation·WAV 출력과 외부 Codex→MCP 흐름을 유지합니다. f0r h3r v6와 클래식 데모가 동봉됩니다.

현재 후보의 집중 회귀 48개, 실제 앱의 가상 CoreMIDI 녹음·take 복원·Undo/Redo·저장·새 프로세스 재열기·10초 WAV 출력을 검증했습니다. 최신 가로·세로 스크린샷도 갱신했습니다. [QA 범위](../../qa/1.0-build245.md).

사용자의 마감 우선 결정에 따라 앱 내 ChatGPT 계정·대화 기능은 1.1로 이월했으며 이번 배포에 포함하지 않습니다. live MIDI 미리듣기는 note-only, bend 기본 범위는 ±2 semitones이며 RPN·hotplug·추가 장치/플러그인 호환성은 후속 작업입니다. 물리 입력/청취·IME·표시 FPS·장시간 영상은 미검증입니다. 기존 영상 최대 70ms 간격 FAIL은 해결된 것으로 표시하지 않습니다.

macOS 14+ Apple Silicon용입니다. ad-hoc 서명이며 Apple 공증은 없습니다. 첫 실행이 차단되면 출처와 SHA256을 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기를 선택하세요. [설치 안내](../install-macos.md). 업데이트 전 곡을 별도 복사해 보관하세요. 문제가 생기면 이전 0.90 앱과 업데이트 전 프로젝트 사본으로 돌아갈 수 있습니다. 코드·문서는 MIT, 음악은 별도 이용 조건입니다.

## English

MIDI recording now preserves notes, sustain (CC64), and pitch bend in channel-specific takes. Restore the pre-recording edit or undo/redo an entire capture atomically. Expression-only overdubs retain existing notes and untouched expression dimensions. Orbital song-form editing, audio/MIDI/step editors, effects, automation, WAV export, and the external Codex→MCP workflow remain available. Includes f0r h3r v6 and classical demos.

Validation covers 48 focused regression tests and a native virtual-CoreMIDI capture, take restoration, Undo/Redo, save, cold reopen, and a nonzero 10-second WAV. Both README screenshots were refreshed. [Exact QA scope](../../qa/1.0-build245.md).

Following the decision to close this version without expanding nonessential work, in-app ChatGPT account/chat integration is deferred to 1.1 and excluded from this release. Live MIDI audition remains note-only; default bend range is ±2 semitones. RPN, hotplug, additional device/plugin compatibility, physical input/listening, IME, compositor FPS and extended video checks remain follow-up work. The earlier maximum 70ms video interval remains a recorded FAIL.

Requires macOS 14+ on Apple Silicon. Ad-hoc signed and not Apple-notarized. If launch is blocked, verify the source/checksum and use System Settings → Privacy & Security → Open Anyway. [Installation guide](../install-macos.md). Back up projects before updating; rollback uses the previous 0.90 app with the pre-update project copy. Code/docs use MIT; music has separate terms.
