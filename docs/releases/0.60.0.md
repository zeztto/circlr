# 0.60.0 — 내장 음색과 데모 표현

상태: RELEASE_READY / ARTIST_REVIEW_PENDING. 기준0.50.1/build169, branch `release/0.60.0`.

## 범위와 완료 조건

- R60-01: 새 Drive의 oversampling으로 고역 aliasing을 줄인다. 기존 effect renderVersion 없음/1/2의 출력은 보존한다. spectral/길이/유한값/채널 격리 회귀를 통과한다.
- R60-02: 기존 악기 편집기에 이름 있는 내장 patch 선택을 제공한다. 저장된 patch를 자동 교체하지 않으며 선택은 기존 Undo 경로를 따른다.
- R60-03: f0r h3r v6의 음색·articulation·구간별 filter 표현을 다듬는다. 120 BPM, F♯ minor,96마디,15트랙,단순한 DJ 드럼과 기존 ID·컬러·배치를 유지한다. 클래식3곡도 유지한다.
- R60-04: 최종 엔진으로 편집 프로젝트·전체 WAV·후렴 stems를 만든다. clipping/peak/loudness/mono 지표 및 권리 검사를 기록한다. 측정값을 음악적 완성도나 실제 청취 결과로 대체하지 않는다.
- R60-05: 실제 최종 앱에서 데모 로드·편집·재생 상태·저장/재열기를 검증하고 가로/세로 스크린샷을 갱신한다. README KO/EN,CHANGELOG,QA,릴리스 노트 갱신 후 독립 검토한다.
- R60-06: main 병합,annotated tag,정식 GitHub Release 및 재다운로드 SHA256 검증.

## 소유 경계

DSP 담당: Audio Drive와 Core version 검증. Preset 담당: 신규 catalog와 악기 편집기. Demo 담당: 재현 가능한 변환 도구와 테스트. Development lead: 번들 적용·렌더·QA·문서·배포 통합. 기존 사용자 프로젝트와 다른 worktree는 변경하지 않는다.

## 검증과 남은 경계

Swift Core/Audio 및 MCP 회귀, 데모 graph/legacy 일치·라이선스 검사, PCM 분석, 실제 별도 QA 앱, 서명·패키지 inventory 검사. 음악의 최종 미적 승인과 물리 장치 청취는 사용자 검토로 구분한다. 이전 버전의 IME/native 유예를 새로운 성공 근거로 재사용하지 않는다.

기술 QA: Swift1,004 PASS/3환경SKIP,MCP63 PASS, 실제 앱과 최종 ZIP 검증 완료. 음악의 최종 미적 승인은 후속 검토로 남긴다. 상세 증거는 [QA](0.60.0-qa.md)를 따른다.
