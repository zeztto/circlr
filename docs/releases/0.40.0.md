# 0.40.0 — 읽기 쉬운 궤도와 재생 감상

상태: **READY_FOR_RELEASE**. 기준: 공개 v0.30.0/build161 + 출고 기록 `88b24de`. 구현 브랜치: `release/0.40.0`. 목표 앱 버전: 0.40.0. 새 바이너리 후보 build162부터 증가한다.

## 목표와 우선순위

최우선은 **가시성**이다. 작은 텍스트·불분명한 선택·입출력·재생 위치 때문에 곡 구조를 읽기 어려운 문제를 줄인다. 기존 다크 모드, 원이 타임라인인 구조, 하나의 자유 배치 캔버스를 유지한다. 고정 좌우 편집 패널을 만들지 않는다.

사용자는 이번 버전의 native QA와 실제 한글 입력 검증을 명시적으로 생략했다. 이를 `USER_WAIVED`로 기록한다. 한글 조합의 marked-text·초안·키 이벤트 보호는 소스와 관련 자동 검사로 검토한다. 실제 화면·청취·프레임 실측을 수행한 것으로 보고하지 않는다.

기존 [로드맵](roadmap.md)의 R40-01–07 범위를 삭제하지 않는다. 가시성 구현을 먼저 진행하고 감상 모드·팔로우·녹화와 통합한다. 각 작은 변경을 0.40 완료로 부르지 않는다.
