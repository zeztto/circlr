# 0.40.0 — 읽기 쉬운 궤도와 재생 감상

상태: **IN_PROGRESS**. 기준: 공개 v0.30.0/build161 + 출고 기록 `88b24de`. 구현 브랜치: `release/0.40.0`. 목표 앱 버전: 0.40.0. 새 바이너리 후보 build162부터 증가한다.

## 목표와 우선순위

최우선은 **가시성**이다. 작은 텍스트·불분명한 선택·입출력·재생 위치 때문에 곡 구조를 읽기 어려운 문제를 줄인다. 기존 다크 모드, 원이 타임라인인 구조, 하나의 자유 배치 캔버스를 유지한다. 고정 좌우 편집 패널을 만들지 않는다.

사용자는 이번 버전의 native QA와 실제 한글 입력 검증을 명시적으로 생략했다. 이를 `USER_WAIVED`로 기록한다. 한글 조합의 marked-text·초안·키 이벤트 보호는 소스와 관련 자동 검사로 검토한다. 실제 화면·청취·프레임 실측을 수행한 것으로 보고하지 않는다.

기존 [로드맵](roadmap.md)의 R40-01–07 범위를 삭제하지 않는다. 가시성 구현을 먼저 진행하고 감상 모드·팔로우·녹화와 통합한다. 각 작은 변경을 0.40 완료로 부르지 않는다.

## 검증 계약

- 소스: 숫자/이름 초안, marked text, 키보드 대상, scene label 측정/그리기, 캔버스·재생 데이터 분리 검토.
- CPU 자동 검사: 관련 Core layout/카메라/시간 정책, 음악 데이터·Undo 불변, JSON 호환과 MCP. Audio 검사는 물리 장치를 사용하지 않는 범위만 선별한다.
- 빌드: 앱과 5 helper, 생성 kit. 가시성 변경은 Swift/AppKit 빌드로 타입·호출 통합을 확인한다.
- 패키지: 새 build, 출처/라이선스, 번들 inventory, 서명, ZIP 복원·다운로드 checksum. 기존 사용자 실행 앱 교체는 하지 않는다.
- `USER_WAIVED`: 실제 앱 클릭/한글 입력, 실제 청취, 영상 재생·장시간 native 프레임 측정. 근거 없는 PASS나 실측값을 만들지 않는다.

### 첫 구현 묶음 · 2026-09-11

- 라벨 제목 14pt/선택 15pt·부제12pt·포트11pt, 표시와 크기 측정을 함께 조정했다. 포트 배지·중립 경계·궤도와 케이블 대비를 강화했다. 확대된 라벨은 기존 충돌 회피를 유지하며 실제 밀집 화면 결과는 native 미검증이다.
- 실제 표시되는 AgentConsole에 두 줄 작업 상태를 추가했다. 접힌 콘솔도 측정한 높이를 viewport에서 제외하도록 리뷰 지적을 수정했다. compact 상단에서 보조 라벨을 줄이고 접근성 이름을 유지했다.
- 숫자 필드의 commit/blur/Return/Tab/Esc/update 경로에 marked-text 보호를 보완했다. 이름 필드와 기존 focus identity 보호를 검토했다. 실제 한글 입력은 실행하지 않았다.
- 곡/섹션/고정 서클, 전체 맞춤/배율 유지, 전환 강도 설정을 Core·상단 메뉴·workspace 저장에 연결했다. 재생 중 제거된 pin은 stale plan에서도 중단하도록 보완했다. MCP·명령 검색 및 감상 모드 통합은 남았다.
- 영상 pixel/PCM 변환·encoder append/finish를 메인 스레드 밖 직렬 queue로 옮기고 대기 프레임을 최대1개로 제한했다. 캡처 전에 readiness/async error를 확인하고 tick을 common runloop mode에 등록했다. 원래 해상도 bitmap 캡처와 반복 오디오/녹화 시간 통합은 남았다.
- 통합 debug 앱 빌드 PASS: `.build/r40-integrated-build.log`. 첫 release 빌드는 소스 수정과 경합하여 실패했고 이후 소스 동결 후 통합 빌드로 재확인했다. 배포 앱을 빌드하거나 교체한 것은 아니다.
- 관련 Core **36/36 PASS**: `.build/r40-core-qa.log`; PlaybackFollowSettings/Framing/Position, NameEditSession/NumberEditSession. 이 수치에 추가로 최초 follow6개 검사를 중복 합산하지 않는다.
- offline 영화 **4/4 PASS**: `.build/r40-movie-tests.log`; MP4 video/audio·PTS·길이 재디코드, 300프레임 burst queue상한, finish drain, cancel 뒤 게시 방지. 실제 FPS·청취·GUI의 증거가 아니다.


### 독립 검토와 checkpoint

`r40_integrated_review`의 P2 지적(비활성 pin이 중간 카메라 이동을 취소한 뒤 재참여해도 캐시가 이동을 막음)을 수정했다. 미완료 animation만 target cache를 무효화해 재개하고, 도착 완료한 같은 pin의 반복에서는 재줌하지 않는다. stale 경계도 함께 처리했다. 수정 후 앱 빌드 PASS: `.build/r40-reviewed-build.log`.
