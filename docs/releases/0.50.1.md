# 0.50.1 — 서클 크기와 자동 정렬

상태: RELEASE_READY. 기준0.50.0/build166, branch `release/0.50.1`.

## 사용자 결과

기능에 따라 서클 크기를 구분하고 기본 배치를 중심에서 밖으로 펼친다. 자동 정렬은 방사형·가로 신호 흐름·세로 신호 흐름을 제공한다. 새 실화면으로 README 스크린샷도 갱신한다.

## 계약과 소유

- Core geometry: `HierarchyScene.swift`의 orbit 기본 크기·간격·신호 흐름 배치. 앨범/곡/섹션과 audio/MIDI/instrument/effect/output을 구별한다. 시각 충돌 해결이 시간 anchor·compiler 결과를 바꾸지 않는다. 사용자 지정 offset은 의도적으로 보존한다.
- Core auto layout: 신규 `HierarchyAutoLayout.swift`. 동일 컨테이너 선택만 atomic하게 정렬한다. 실제 반경·연결 방향을 반영하고 고정된 결과를 제공한다. 그룹과 비선택 서클을 고려한다.
- App: `AlbumWorkspace.swift`, `CanvasCommands.swift`, `RootView.swift`. 선택2개 이상 또는 현재 컨테이너의 자식을 대상으로 한다. 우클릭·상단 도구·명령 검색이 같은 명령을 호출한다. 한 번 Undo와 fresh focus를 보장한다.
- QA/docs/release: development-lead. 음악/시간/연결 불변, 크기·여백 회귀, 3종 정렬·Undo, 가로·세로 native, 실제 새 screenshot, 독립 검토 후 패키징한다. 새로운0.60 음악 기능은 포함하지 않는다.
