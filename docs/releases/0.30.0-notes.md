## English

This release refines the basic production workflow and bundles the latest **f0r h3r v5** demo with section and track-circle colors.

- Choose **File → 데모곡 불러오기…** to open a new editable copy. Each copy has a new project ID; the bundled original stays intact. Existing unsaved work goes through the normal confirmation flow, and an edited demo can be saved to a new location.
- v5 preserves the music and audio from v4 and adds circle colors. The assets ship with the app, so opening the demo needs no separate download.
- Improves label, plus and chevron contrast in the **Add Circle** menu on the dark canvas.
- Includes earlier 0.30 improvements to asynchronous MIDI reading, pedal input, step-editor Tab navigation, pedal-field access above a tall console, and the running version/build display.

Apple Silicon only; the app requires macOS 14 or later. No Intel binary is included. The candidate is ad-hoc signed and is not Apple-notarized. The public source code and documentation use MIT; demo music has separate terms and CC0 asset notices. Preserve the previous app and a project copy saved by that version before extracting the ZIP. Once the ZIP and `SHA256SUMS` are published, place them together and run `shasum -a 256 -c SHA256SUMS`.

The demo includes **six CC0-1.0 percussion assets** from Roberto's FreePats synthesizer percussion release dated 2022-07-18, with source and license notices. This does not license the whole composition under CC0. User projects, personal settings and credentials are excluded from distribution.

Current regression checks passed **827 Swift Core/selected Audio tests**, **29 Python MCP tests** and **six demo-packaging tests**. On build160, real Scarlett 6i6 USB playback, natural completion, replay and stop were observed, and the user confirmed normal audible output. This is evidence for that device, not universal device or plug-in compatibility. The user explicitly waived physical Korean IME verification and the remaining native QA for this release on 2026-09-11. Untested items remain recorded in the [final QA record](0.30.0-final-qa.md); the waiver is not a test pass.

The startup screen and expanded features planned for 0.40 are not claimed as delivered in this release. This is a regular GitHub release with the recorded user QA waiver.
