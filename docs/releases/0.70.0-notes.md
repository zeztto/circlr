# circlr 0.70.0 · build180

## 한국어

재생 비주얼라이저의 반복적인 가시성·라벨·포트 계산과 불필요한 팔로우 탐색을 줄였습니다. 녹화 중 중복 캔버스 그리기를 없애고 캡처 프레임을 화면에 재사용합니다. 감상 모드 버튼은 상단 녹화 버튼 바로 옆에 있으며 `⇧⌘V`로 진입하고 `Esc`로 복귀할 수 있습니다. 곡 데이터와 프로젝트 schema는 변경하지 않았으며, 동봉 데모는 **f0r h3r v6**와 클래식 3곡입니다.

동일 곡 첫 섹션·비슷한 창에서 재생 시각 업데이트는 이전 0.60.0 build170의 15.27Hz에서 수정 후보 build172의 56.82Hz였습니다. 이는 **앱 콜백 빈도**이며 실제 화면 표시 FPS가 아닙니다. 최종 build180의 가로 MP4는 1920×942·64.93초·1939 decoded 프레임·평균29.86fps였고, 2프레임 초과 PTS 공백과 연속 완전 동일 이미지는 0개였습니다. 곡 단위 팔로우의 가로 1912×1080·25.43초 및 세로 670×1080·23.77초 녹화에서도 해당 공백과 연속 동일 이미지가 0개였습니다. 전체 Swift 테스트 1007개 실행·3개 skip·실패0; Python MCP 35개는 build179 기준 통과했습니다.

**확인되지 않은 항목:** 실제 compositor 표시 FPS, 정확한 1920×1080·10분 녹화, 영상 중간·끝의 AV offset, 실제 플레이어 시청·청취, 고밀도/루프/최소화 시 장시간 동작은 통과로 표기하지 않습니다. 사용자의 정식 출고 지시에 따라 이 미검증 범위를 공개하고 릴리스합니다. 음악적 발매 수준 검토도 별도입니다. [전체 QA 기록](https://github.com/zeztto/circlr/blob/v0.70.0/docs/releases/0.70.0-qa.md).

macOS 14 이상 Apple Silicon용. 패키지는 ad-hoc 서명이며 Apple 공증을 받지 않았습니다. 첫 실행이 차단되면 [macOS 설치·첫 실행 안내](https://github.com/zeztto/circlr/blob/v0.70.0/docs/install-macos.md#한국어)를 따르세요. 문제 발생 시 기존 앱과 백업한 프로젝트를 사용해 복구하세요.

## English

Playback rendering now reuses visibility, label and port calculations and avoids unnecessary follow traversal. Recording removes duplicate canvas draws and reuses captured frames on screen. Viewing mode sits beside Record in the top bar; enter with `⇧⌘V` and leave with `Esc`. Project schema and music content are unchanged; the bundle retains **f0r h3r v6** and three classical demos.

On the same song section and comparable canvas, visual update callbacks increased from 15.27Hz on 0.60.0 build170 to 56.82Hz on the revised build172 candidate. These are **app callbacks, not displayed FPS**. The final build180 landscape MP4 is 1920×942, 64.93 seconds, 1939 decoded frames at a 29.86fps average, with no PTS gap longer than two target frames and no adjacent pixel-identical frames. Separate song-follow recordings at 1912×1080 for 25.43 seconds and 670×1080 for 23.77 seconds also showed neither condition. Swift tests: 1007 run, 3 skipped, 0 failed; 35 Python MCP tests passed on build179.

**Open verification:** actual compositor FPS, an exact 1920×1080 ten-minute recording, mid/end audio-video offset, playback and listening in an external player, and sustained high-density, loop and minimize/restore scenarios are unverified. They are disclosed because this is a user-directed formal release, not marked as passing QA. Artist-level music approval is separate. [Full QA record](https://github.com/zeztto/circlr/blob/v0.70.0/docs/releases/0.70.0-qa.md).

For Apple Silicon with macOS 14+. The app is ad-hoc signed and is not Apple-notarized. If Gatekeeper blocks first launch, use the [installation instructions](https://github.com/zeztto/circlr/blob/v0.70.0/docs/install-macos.md#english). Keep your previous app and a project backup for rollback.
