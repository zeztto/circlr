## English

Fixed a floating-point boundary error that could display a loop iteration one cycle behind. Audio PCM and continuous playback-position interpolation are unchanged. The bundled f0r h3r v6 and classical demos, MIT code/documentation, and separate music terms are retained.

Validation covers 100 offline cycles, related regression tests, and a native MIDI edit/Undo/save, song and section loop, WAV export, and cold-reopen journey. Both README screenshots now show build243.

Following the user's direction to close the version without expanding nonessential work, extended video/device/IME checks move to follow-up work. The previous 70ms video interval remains a recorded FAIL; physical listening, compositor FPS, and legacy Scarlett compatibility remain unverified. [QA scope and deferred work](../../qa/0.90-build243.md).

Requires macOS 14+ on Apple Silicon. Ad-hoc signed, not notarized by Apple. If first launch is blocked, verify the download and use System Settings → Privacy & Security → Open Anyway. [Installation guide](../install-macos.md).
