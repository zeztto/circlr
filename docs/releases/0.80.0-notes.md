## 한국어

써클러 0.80은 곡의 섹션을 궤도에서 정리하고, MIDI·오디오·이펙트로 한 곡을 제작한 뒤 외부 Codex가 MCP로 실제 편집에 참여할 수 있는 Apple Silicon용 업데이트입니다.

### 주요 변경

- 가로·세로 창의 두 줄 상단바와 선택창, 콘솔 옆 캔버스 배치, 미디어 라이브러리 폴더·형식 필터의 키보드·포인터 조작을 다듬었습니다. 큰 샘플 목록에서는 Tab마다 전체 결과를 다시 훑지 않도록 했습니다.
- 앱 안에서 녹음 입력을 선택하고 격리 worker로 take를 만듭니다. 시스템 기본 오디오 장치는 바꾸지 않습니다. 재생은 일반 Space, 라이브러리 미리 듣기는 `⌥Space`로 구분합니다.
- 외부 Codex의 동봉 circlr MCP 작업을 앱 콘솔에서 볼 수 있습니다. 앱 안의 Codex 계정 로그인·대화와 AI turn STOP은 후속 기능입니다.
- 곡/섹션 루프, 감상 모드, MP4 캡처와 프로젝트 저장·재열기·WAV/stems 출력을 계속 개선했습니다. 동봉 데모와 원본 음악 자산의 권리 조건은 유지됩니다.

### 설치 및 호환

- 로컬 검토 후보 `circlr-0.80.0-build242-macos-arm64.zip`은 macOS 14 이상 Apple Silicon용입니다. 압축 해제·서명·초기 창 검증은 통과했으며 정식 자산으로 게시되지 않았습니다. native QA는 macOS 26에서 수행했습니다.
- 앱은 ad-hoc 서명됐으며 Apple 공증을 받지 않았습니다. 첫 실행이 차단되면 ZIP과 `SHA256SUMS`를 확인하고 [macOS 설치·보안 경고 안내](https://github.com/zeztto/circlr/blob/release/0.80.0/docs/install-macos.md#한국어)를 따르세요.
- 기존 프로젝트를 열기 전 백업을 보관하세요. 새 형식으로 저장한 프로젝트는 이전 앱에서 열리지 않을 수 있습니다. 문제가 생기면 이전 앱과 그 앱에서 만든 프로젝트 백업을 함께 복원하세요.
- ZIP과 `SHA256SUMS`를 같은 폴더에 내려받고 `shasum -a 256 -c SHA256SUMS`로 무결성을 확인할 수 있습니다.

- build241의 700×600pt 필터 키보드/포인터와 overlay 밖 `⌥Space` 무재생·일반 Space 재생 시작/취소는 실제 앱에서 통과했습니다. 실제 한글 IME 조합, Fn+Space의 macOS 처리, 큰 폴더의 체감 입력 지연은 아직 확인하지 못했습니다.
- build241 실제 1080p·10분 MP4에는 사전 프레임 간격 기준 초과가 3곳 있었습니다. build242에서 제한된 보간을 추가한 뒤 같은 조건에서 한 곳으로 줄었으나 최대 70.0ms로 사전 상한 66.67ms를 넘었습니다. 영상 gate는 여전히 실패입니다. [영상 QA](https://github.com/zeztto/circlr/blob/release/0.80.0/qa/0.80-build242-performance.md).

## English

circlr 0.80 lets songwriters arrange sections on time orbits, build a song with MIDI, audio and effects, and watch an external Codex agent make a real edit through MCP on Apple Silicon.

### Changes

- Refined the two-row toolbar, pickers, canvas space beside the console, and keyboard and pointer controls for media folder and type filters in landscape and portrait windows. Tab traversal no longer scans every item in a large sample result list.
- Added app-specific recording input selection through an isolated worker without changing the macOS default audio device. Plain Space controls song playback; `⌥Space` previews a library file.
- External Codex activity through the bundled circlr MCP appears in the app console. In-app Codex account login, chat and AI-turn STOP are later work.
- Improved song and section loops, viewing mode, MP4 capture, project save/reopen and WAV/stem output. Bundled demos retain their separate music terms.

### Installation and compatibility

- The local review candidate `circlr-0.80.0-build242-macos-arm64.zip` targets Apple Silicon on macOS 14 or later. Archive extraction, signing and initial-window checks passed; it has not been published as a release asset. Native QA ran on macOS 26.
- The app is ad-hoc signed and is not Apple-notarized. Verify the ZIP against `SHA256SUMS`; if Gatekeeper blocks first launch, follow the [macOS installation guide](https://github.com/zeztto/circlr/blob/release/0.80.0/docs/install-macos.md#english).
- Back up existing projects before opening them. A project saved in a newer format may not open in an older app. For rollback, restore both the earlier app and a compatible project backup.
- Download the ZIP and `SHA256SUMS` into the same directory, then run `shasum -a 256 -c SHA256SUMS`.

### Verification and limitations

- On the same build242 source: **1,340 Swift tests run, 15 skipped, 0 failed**; **47+39 Python MCP tests** and **23 agent-kit/model-trace tests** passed. The arm64 app and seven helpers passed strict deep signing checks; bundled demos, agent kit and license files matched source byte for byte. [Integration QA](https://github.com/zeztto/circlr/blob/release/0.80.0/qa/0.80-build242.md).
- In an isolated app, an external Codex model edited one MIDI step; independent QA checked console activity, Undo, save/reopen and a nonzero WAV. Separate native journeys checked blank-song production and persistence of a CalDigit audio take through WAV export. These are bounded observations, not a guarantee for every device, plug-in or project.
- In a 700×600pt native window, media-filter keyboard/pointer controls, `⌥Space` not starting song playback outside the library, and plain Space start/cancel passed. Korean IME composition, macOS handling of Fn+Space and latency in a very large folder remain unverified.
- The build241 native 1080p ten-minute MP4 exceeded the preset maximum frame gap in three places. Build242 reduced this to one, but the remaining 70.0ms gap still exceeds the preset 66.67ms limit. The video gate remains failed. [Video QA](https://github.com/zeztto/circlr/blob/release/0.80.0/qa/0.80-build242-performance.md).
- Actual compositor-present FPS and physical listening remain unverified. Do not assume the older Scarlett 6i6 works on the current macOS version. App-only Mac Studio output and CalDigit input were used for file and state checks; the recorded CalDigit signal was very quiet. [Full release gates](https://github.com/zeztto/circlr/blob/release/0.80.0/qa/0.80-release-gates.md).
