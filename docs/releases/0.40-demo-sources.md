The individual official catalog and original source headers explicitly mark each transcription Public Domain. This decision does not rely merely on a composer's age. Underlying notes and sources remain unrestricted by circlr demo conditions; newly authored project additions have separately scoped usage terms in `classical/ARRANGEMENT-TERMS.md`.

## Reproduction

`python3 scripts/build-classical-demos.py` regenerates only its three project manifests and provenance records. It downloads the official sources only if the local copy is missing and verifies the MIDI hashes before parsing. `--check` compares generated bytes with committed files without modifying them. No dependencies beyond Python's standard library.

Each note's pitch, velocity, start and duration is preserved. Two original performing voices become two named tracks, with MIDI → instrument → output connections. Section and instrument colors differ; MIDI keeps its type color. Section names describe the circlr listening route, not a scholarly formal analysis. MIDI repeats are already unfolded by the source; no inferred repeats are added. All cuts use nearby whole-bar boundaries where neither voice sustains across the boundary: no tied note splitting, clipping or retrigger is necessary. Final bars are padded with silence where the source ends partway through a bar.

| Work | BPM / meter | Section boundaries (quarter beats) | Last source note / project end |
|---|---|---|---|
| BWV 779 | 90 / 3/4 | 0, 24, 48, 72, 102 | 100 / 102 |
| BWV 778 | 90 / 4/4 | 0, 24, 48, 72, 92 | 92 / 92 |
| WoO 59 | 72 / 3/8 | 0, 36, 66, 96, 126, 157.5 | 156.5 / 157.5 |

Source audio-preview duration is approximately 66.667 / 61.333 / 130.417 seconds; generated body duration is 68 / 61.333 / 131.25 seconds. Effect/instrument release tails are separate. Elise has constant CC7=100 on both voices, incorporated into each track's gain. These source files contain no pitch-bend or sustain-pedal events to omit.

## Validation boundary

Python reconstruction and deterministic regeneration pass for all 1,976 notes. All MIDI files are format 1, three tracks including metadata, 384 PPQ. Each `provenance.json` records source hashes, exact note counts and section boundaries. App-native Project decoding/compiler and independent MIDIImport comparison are performed by `scripts/build-classical-demos-verify.swift` when the build is available. Native UI/audio listening QA is explicitly waived for 0.40; offline data checks do not establish subjective mix quality.
