# circlr 1.2.0 · build253

## 한국어

MIDI 구절을 옮기고, 후반부터 듣고, 루프를 재생하면서 수정하는 제작 흐름을 개선했습니다.

- **구절 전송:** MIDI 편집기에서 ⌘C/X/V로 선택 노트를 다른 서클·트랙·섹션으로 옮깁니다. ⇧⌘V는 원래 박에 붙여넣습니다. 상대 박·길이·세기를 보존하며 전체 구절이 대상 길이에 맞지 않으면 변경하지 않습니다. 편집은 한 번의 Undo로 되돌립니다.
- **커서 재생:** ‘커서부터 듣기’ 또는 MIDI 편집기의 ⌥⌘Return으로 선택 섹션의 후반부터 재생합니다. 공유 리듬 패턴에서는 사용할 수 없습니다. 기본 Play는 기존 시작 동작을 유지합니다.
- **재생 중 루프 편집:** 노트 수정·Undo를 렌더링한 후 준비된 다음 루프 경계에서 교체합니다. 준비 실패 시 기존 루프를 유지합니다. 이미 출력에 제출된 revision은 최신 편집이 준비되어 후속 경계에 적용될 때까지 재생될 수 있습니다. 영상 녹화 중에는 편집을 다음 재생에 반영합니다.
- **송폼 재사용:** 섹션 우클릭 → ‘이 섹션 뒤에 재사용’으로 공유 섹션을 곡 흐름에 삽입합니다. 반복·이번 사용 설정과 기존 다음 전환을 보존합니다. 복잡한 분기·순환은 변경 없이 거절합니다.

계정 대화의 실서비스 검증은 보류했고 패키지 UI에서는 비활성화했습니다. 기존 로컬 명령 콘솔·외부 Codex → MCP는 계속 사용할 수 있습니다. 추가 OpenAI 모델 호출은 하지 않았습니다.

실제 앱에서 다른 트랙·섹션 전송, Undo/Redo, 5초 커서 시작, 중단 없는 루프 revision 교체와 PCM 변경, 공유 섹션 재생 순서, 바운스, 저장·cold reopen, 26초 48kHz stereo24-bit WAV를 확인했습니다. Core736개·Python MCP39개 회귀와 변경별 App/Audio 집중 테스트, 독립 검토를 수행했습니다. [QA 범위와 증거](../../qa/1.2-production-workflow.md).

**설치:** Apple Silicon용 ZIP을 풀어 앱을 실행합니다. 앱은 ad-hoc 서명이고 Apple 공증은 없습니다. macOS가 차단하면 출처·체크섬 확인 후 시스템 설정 → 개인정보 보호 및 보안 → ‘그래도 열기’를 사용하세요. [설치 안내](../install-macos.md).

**남은 제한:** 물리 청취·Scarlett 호환성·광범위 IME/VoiceOver·장시간 영상/실제 표시 FPS는 이번 검증에 포함되지 않습니다. 기존 영상70ms 간격 FAIL은 해결되지 않았습니다. 동기화 overdub·count-in/metronome은 후속 범위입니다. 중요한 프로젝트는 사본으로 시험하고 문제 발생 시 이전 앱과 프로젝트 백업을 사용하세요. 설치된 앱을 자동으로 교체하지 않습니다.

## English

This release improves the cycle of moving MIDI phrases, listening from a later point, and editing while a loop keeps playing.

- **Phrase transfer:** Use ⌘C/X/V inside a MIDI editor to copy, cut and paste selected notes between circles, tracks and sections. ⇧⌘V preserves the original starting beat. Relative timing, lengths and velocities are retained; a phrase that cannot fit is rejected without partial edits. Each edit has a single Undo step.
- **Cursor playback:** ‘커서부터 듣기’ or ⌥⌘Return in a MIDI editor starts the selected section at its editing cursor. Shared rhythm patterns are excluded. Normal Play retains its existing start behavior.
- **Live loop edits:** New edits and Undo are rendered and switched at the next prepared loop boundary. Failure keeps the current loop playing. A revision already submitted to the output queue may keep playing until the newest edit is ready and applied at a later boundary. During video recording, edits take effect on the next playback instead.
- **Reuse in song flow:** Right-click a section and choose ‘이 섹션 뒤에 재사용’ to insert a shared occurrence immediately after it. Repeats, occurrence settings and the outgoing transition are preserved. Unsupported branches and cycles are rejected atomically.

In-app account chat is hidden while live-service validation is paused. The local command console and external Codex → MCP integration remain available. No additional OpenAI model calls were made.

Native checks cover phrase transfer, Undo/Redo, a five-second cursor start, continuous loop revision/PCM replacement, reused-section playback order, bounce, save/cold reopen, and a 26-second 48kHz stereo 24-bit WAV. Regression evidence includes 736 Core tests, 39 Python MCP tests, focused App/Audio tests and independent review. [QA evidence and scope](../../qa/1.2-production-workflow.md).

**Install:** Extract the Apple Silicon ZIP. The app is ad-hoc signed and not notarized. If macOS blocks it, verify its source/checksum and use System Settings → Privacy & Security → Open Anyway. [Installation guidance](../install-macos.md#english).

**Limits:** Physical listening, Scarlett compatibility, broad IME/VoiceOver coverage, long video recording and measured display FPS remain unverified here. The existing 70ms video-interval failure is unresolved. Synchronized overdub and count-in/metronome remain follow-up work. Test copies of important projects; retain the previous app and project backup for rollback. Your installed app is not replaced automatically.
