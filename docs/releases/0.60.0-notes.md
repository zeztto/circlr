- Choose12 factory patches through the existing sound browser, covering all10 synth voices. Selection uses the existing Undo flow.
- MCP `sounds` returns the same stable preset IDs and exact `synthPatch` values.
- Newly created Drive effects use4×oversampling to reduce high-frequency foldback. Previously saved Drive sounds retain their original renderer. Allow mix headroom after strong distortion.

Requires macOS14+ on Apple Silicon. Ad-hoc signed, not Apple-notarized. See [installation instructions](../install-macos.md#english) and [QA evidence](0.60.0-qa.md).
