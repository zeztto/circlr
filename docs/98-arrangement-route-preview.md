# 편곡안 목록의 연결 경로 미리보기

상태: build84 Core·Release·native 및 QA checker 대조 통과. [QA](../qa/arrangement-route-review.md).

목표: 이름과 섹션 수가 같은 편곡안도 실제 연결 순서와 반복 구조를 보고 구분한다. 기존 편곡안 목록의 각 행 안에 표시하며 별도 화면이나 조작 깊이를 추가하지 않는다.

## 표시 계약

- 각 편곡안 행에서 연결을 따라가는 섹션 순서와 반복 횟수를 확인한다. 저장 배열 순서를 실제 경로처럼 표시하지 않는다.
- 편곡안에 포함되어 있으나 선택된 연결 경로에서 제외된 섹션을 구분한다.
- 경로를 결정할 수 없는 topology 오류는 해당 행에 설명한다. 유효한 경로처럼 보이는 대체 값을 만들지 않는다.
- 현재 편곡 표시·검색·전환·이름 변경·복제와 기존 키보드 동선을 유지한다. 긴 이름과 작은 창에서도 중요한 상태와 선택 동작을 확인할 수 있어야 한다.

## 계산 경계

경로 해석은 `ArrangementCompiler`의 경로 cursor를 공유한다. UI만의 별도 순회 규칙을 만들지 않고 재생 경로의 순서·반복·제외·오류 판정을 같은 근거에서 얻는다. 목록 확인은 음악 데이터나 현재 재생 편곡을 변경하지 않는다.

이 미리보기는 연결 구조를 보여준다. 음원·악기·파일의 유효성, 정확한 재생 시간, 실제 출력 성공과 청취 품질을 검증하거나 보장하는 표시로 사용하지 않는다. 기존 출력 출고 조건을 유지한다.

## 검증 기준

1. 연결 순서가 저장 순서와 다른 안에서 compiler와 목록 순서가 일치한다.
2. 반복 횟수와 경로에서 제외된 섹션이 구분되고 topology 오류가 정상 경로로 보이지 않는다.
3. 같은 이름·같은 섹션 수의 원안과 대안을 연결 구조로 구별한다.
4. 실제 목록에서 작은 창·긴 이름·검색·키보드 전환을 확인하고 기존 복제·이름 변경 조작을 유지한다.
5. 섹션 연결/순서를 변경한 뒤 원안·대안 전환, Undo와 저장/재열기에서 음악과 표시의 일치를 확인한다.
