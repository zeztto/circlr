# 궤도 타임라인과 편집

써클러의 시간 서클은 12시에서 시작하고 시계 방향으로 진행한다. 부모의 원 한 바퀴는 부모의 실제 실행 시간이다. 시작 위치가 같은 소스는 같은 각도에 놓이고, 다른 동심 궤도를 사용한다. 공간상의 크기나 줌은 음악의 길이를 바꾸지 않는다.

## 계층별 의미

| 서클 | 한 바퀴 | 작은 서클의 배치 |
| --- | --- | --- |
| 앨범 | 선택된 곡·악장의 총 실행 시간 | 배열 순서와 각 곡·악장의 반복 |
| 곡·악장 | 그 내용의 한 번 실행 | 하위 악장 또는 선택된 섹션 경로 |
| 섹션 | 해당 사용의 MusicClock | 소스 시작과 실제 반복 구간 |
| MIDI | 소스의 로컬 박 길이 | 각 노트의 시작·길이·음높이 |
| 오디오 | 로컬 음악 시간 | clip의 시작과 재생 구간, 별도 원본 초 단위 trim |
| 악기·이펙터·믹스·출력 | 시간 위치를 갖지 않음 | 실제 MIDI/audio/sidechain 신호 연결 |

각도는 `seconds / duration × 2π − π/2`로 계산한다. 마디는 균등 분할하지 않는다. 변박과 tempo map을 거친 `MusicClock.seconds(at:)`가 마디 tick의 위치를 정한다. 곡의 섹션 위치에는 실제 compiler의 반복·within/insert/overlap 전환을 사용한다. 재생 경로 밖의 섹션은 시간 궤도를 부여하지 않으며, 경로에 문제가 있어도 편집용 캔버스는 유지한다.

MIDI 소스의 시작 박과 반복은 기존 scheduler를 따른다. 오디오는 길이를 지정한 서클에서는 그 길이를 주기로 반복하고, 길이를 지정하지 않은 서클에서는 실제 clip 길이를 주기로 반복한다. 음원 파일의 초와 음악의 박을 서로 바꾸어 저장하지 않는다. 바운스의 잔향은 기존 오디오 renderer가 보존한다.

## 조작

연결 조작은 향후 [8방향 IN/OUT 포트](22-eight-direction-ports.md)로 확장한다. 연결점의 각도는 아래의 음악 시작 시간·순서 손잡이와 독립적이며, 포트 위치를 옮겨도 재생 시간이 바뀌지 않는다. 현재 0.10.0은 좌우 포트 UI를 사용한다.

- 휠은 포인터를 중심으로 확대·축소한다. 두 번 클릭하면 해당 서클로 들어가고 Esc나 경로 버튼으로 나온다.
- 원형 소스를 선택하면 흰색 **시작 시간** 손잡이가 나타난다. 부모 궤도에서 손잡이를 끌면 부모 BeatGrid에 맞춰 시작 박을 바꾼다. 한 gesture는 한 Undo다.
- 섹션·곡·악장의 **순서 이동** 손잡이는 형제들의 재생 순서를 바꾼다. 섹션은 분기 없는 전체 경로에서 동작한다. 마지막으로 옮겨져 사라질 전환 효과가 있으면 적용하지 않는다. 분기와 전환은 명시적인 연결 편집으로 조정한다.
- MIDI 서클을 확대하면 동심 음높이 줄과 시간 원호가 나타난다. 빈 원호에 노트를 추가하고, 몸체를 끌어 시간과 음높이를 함께 바꾸며, 끝 점으로 길이를 조절한다. 옥타브 버튼과 시작·길이·세기 수치도 같은 canvas에서 사용한다.
- 오디오는 바깥쪽에 음악의 재생 시간, 안쪽에 원본 파일 전체 파형을 표시한다. 시작·끝 손잡이는 원본의 초 단위 구간을 바꾼다. 조용한 음원은 파형 표시 배율만 자동 조절하며 배율을 표시한다. 오디오 gain에는 영향을 주지 않는다.
- 콘솔을 접으면 상세 편집에 더 많은 높이를 사용한다. Ctrl+`로 다시 펼쳐 실제 에이전트 로그를 본다.
- 그리드 메뉴의 **궤도 타임라인**을 끄면 기존 자유 배치로 돌아간다. 자유 배치 좌표는 별도로 보존된다. 공간 정렬·그룹은 음악 순서를 바꾸지 않는다.

## 구현 경계

`OrbitTimeline`은 초/각도 변환과 tick, `OrbitPlacement`는 음악상의 owner와 실제 실행 interval을 갖는다. 시각적 그룹을 생성하거나 접어도 owner와 시간은 바뀌지 않는다. 그룹의 여백이 상위 궤도의 위치를 바꾸지 않도록 음악 배치의 반경과 시각적 그룹 외곽을 구분한다.

`HierarchySceneBuilder`는 Project에서 이 데이터를 계산한다. orbit/freeform은 Project의 선택적 `circleLayout`에 저장하며 이전 파일에 필드가 없으면 orbit을 기본으로 사용한다. 기존 Layout 좌표를 시간 데이터로 해석하거나 덮어쓰지 않는다.

GUI와 MCP는 같은 Project 편집 경로와 Undo를 사용한다. MCP `inspect`의 `circles`에서 초 단위 timeline/interval/owner를 읽을 수 있다. `set_node.startBeat`는 소스 시작, `reorder_section`은 섹션 순서, `set_clip`은 원본 trim을 편집한다. `focus.compositionID`는 곡·악장을 보여준다. 에이전트의 음악 편집은 카메라 이동 없이 가능하다.

현재 오디오 엔진은 prepared PCM을 재생한다. 재생 중 편집은 다음 재생에 반영하며, 이전 revision의 재생을 새 타임라인 playhead로 표시하지 않는다. plugin PDC·crash isolation·연속 realtime graph 편집과 text/image/video 세계관 참조는 이 구현과 별도의 후속 범위다.
