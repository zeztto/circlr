# 오디오 가져오기 대상 가시성 — build79

문제: 섹션 선택은 selectedTrackID를 초기화하지 않는데, 파일 메뉴는 이 값을 무조건 오디오 대상으로 사용했다. 이전 드럼/신스 편집을 마치고 섹션으로 돌아온 사용자에게 숨은 대상이었다. 라이브러리에는 대상 변경 UI가 있지만 OS 파일 선택 창에는 표시가 없었다.

UX 계약: 개별 음악 서클을 선택했을 때만 그 트랙을 초기 대상으로 삼는다. 섹션·그룹·상위 컨테이너에서는 새 트랙이다. 패턴 가져오기는 기존 범위를 유지한다. OS 파일 선택 창에서 섹션·대상 트랙·1기반 시작 박·원본/이번 사용을 표시한다. 여러 파일은 각각 새 트랙, 패턴은 같은 패턴이라는 차이를 표시한다. 새 확인 단계는 추가하지 않는다. 라이브러리의 명시적 대상 변경 기능은 유지한다.

검증 계획: 이전 트랙 선택→섹션→가져오기에서 새 트랙 표시와 실제 적용, 음악 서클에서 기존 트랙 표시, 다중/패턴 안내, 취소/Undo/저장 복원, 기존 음악과 원본 자산 보존. 물리 출력/입력은 시작하지 않는다.

결과: 관련16개 테스트, release64.20초, native5상태와 실제 파일 가져오기·Undo·재열기·전체 음악/패키지 비교 통과. 기존 트랙 대상은 파일 창에서 확인했고 단일/다중/패턴 적용은 Core 테스트 범위를 구별한다. [QA](../qa/import-destination-review.md).
